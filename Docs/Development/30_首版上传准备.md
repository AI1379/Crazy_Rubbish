# 首版上传准备（2026-10-18，0.1.0）

本期只补首版发布所需的入口、提示和验收，不扩充新的经济或生产系统。

## 本期进展

- 标题显示实际程序版本；首版标为0.1.0。标题菜单与底部设置都能打开可滚动的操作说明，说明人物移动后待命、恢复工作、手动发薪、原料工具、存读档和退出。阅读说明期间停止经营，关闭后保留原暂停与速度状态。
- 新增单条产线缺工具提醒。按实时设施条件判断，点击可列出并定位缺工具设施；补充可用工具后消失，手动停工设施不计入。只读提醒不购买、不搬运、不发薪。
- 发布验收从旧Prototype Demo改为当前S6Plan入口，检查版本、正式构建标记、零资金开局、存读档、自动化、三区与返程、教程及查阅。保留旧Demo作为历史回归，不作为新版本的发布凭据。
- 正式构建使用非Development模式。公开玩家包只附当前玩家说明、已知问题和字体授权；排除调试符号及Unity标记为不应随包发布的备份目录。
- 整理独立的玩家ZIP和源码ZIP，提供版本、校验值、验证记录与上传说明。上传玩家ZIP无需下载Unity或源码。

保存目录和配置数据版本不变；应用名称与公司标识保持原值，避免切换版本后意外换到新存档目录。正式工程目标Unity2022.3.62f3，本机使用2022.3.22f1验证。

验证结果：233项规则回归和25项发布脚本检查通过。实际0.1.0非Development构建已通过无图形验收，确认为当前S6Plan而非旧Demo。1280×800、1920×1080运行检查均通过，覆盖本期标题帮助、说明暂停/恢复、缺工具提醒与定位、补充工具后消除提醒，以及既有存读档、自动化和返程。184分钟真实经营记录的存读档与继续经营通过。最终ZIP的解压复验结果记录在交付文件“首版验收.json”。
