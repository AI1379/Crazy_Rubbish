## 本轮内容

起步拾取、现场木工、拆解、建设、发电、招募、居民运输、动态外销和手动工资继续保留。新增：

- 开始、继续最近有效存档、目标菜单、阶段达成和失败界面；菜单冻结模拟，达成后可以继续经营。新局另开存档槽，不删除旧局。
- 点击地图走四邻格路径；点击设施会走到正面，WASD 或 Esc 可取消。仓库完整目录中的“拾”按钮，远处先导航，抵达后再次点击才实际拾取。
- 主角及居民每300秒实际消耗食物1和饮水1；仓库、钱包、生活零售与外部采购分别记账。主角使用经营现金外购，居民外购使用个人现金，不额外生成库存。
- 首次计划发薪前免费领取；其后可在人员页切换收费、免费、半价补贴。个人外购和紧急饮水可开关；缺货与买不起分别提示，缺供每10秒重试，补齐欠缺量后在180秒内恢复效率。
- 外销保留两轮全人口饮水。免费饮水受每600秒每人2升额度限制，只用现有实物。房租先保障饮食，再只使用超过4钱保护额的余额，进入社区账户。
- 空闲居民优先把地面生活用品运到仓库，再执行工具、燃料、输出和生产供料。发电燃料可从地面实际搬运；灰渣可以实际运回仓库。
- 工作台装配手锯、锤子和螺丝刀：木柄1 + 对应工作端1，人工20/20/15秒。需要主角到场投料与作业；输入预约、暂停/退出保留、取消释放、完批出料及唯一工具实例接入。
- 替补工具自动采购默认关闭，开启后每600秒预算20钱、每种最多1把，并保护全部欠薪和下一期工资。采购与生产补给仍需运输。自动制作补给台尚未接入。
- 欠薪3个等价周期触发暴动；人工停工、生活消费继续，240秒窗口内补发固定目标（开启时欠款的1/3）。平息保留剩余欠薪；下期发薪检查点才再次判断。主角长期缺水/食物或暴动超时进入失败；死亡居民的钱包和旧工资归社区，已有携货返仓或留旧址。
- 木料、工具、纺织、金属技术交易在界面可用；确认显示一次收入和永久最低价影响，确认窗口不暂停模拟。

## 试玩目标

目标菜单给出八项，可自由安排顺序：拾取起步材料、搭建木工、完成两批木板、建设工作台和拆解地点、发电并招募5人、付清首期工资、制作一把替补工具、无缺供无欠薪且现金达到200。达到后显示用时和工资，允许继续经营。

200钱是既有第二区地价的准备目标；本轮没有生成第二区地形，也没有扣款购买未实现地区。阶段达成不能当作游戏通关或返程结局。

## 推荐操作路线

1. 拾手锯，把饮水24、食物12及起步木料/紧固件送进仓库。生活物资开局就在地面，先保障主角吃喝。
2. 木料4 + 紧固件2建木工，另准备同样材料建拆解地点。木工正面投木料8，按F加工两批，取成品送仓库。
3. 留木板4 + 钢铁零件2建工作台；收集钢铁零件6、热动力/发电组件各1、电线2组装发电机，实际投入燃料。
4. 搬旧切割装置及螺丝刀到拆解地点，操作拆解，取出电机、锯片和零件。发电后招募5人，将手锯交接给木工槽并指定1名居民木工。
5. 维持原料和仓库空间，外销木板，第一人加入600秒后手动付清50钱工资。生活政策默认在此时转为收费。
6. 木工切换木柄配方；等旧批次和输出清理完毕。取木柄1，购买手锯锯片1，携带到工作台投料并作业，生成一把替补手锯；再切回木板。
7. 通过拆解回收、产品销售或技术交易筹备200钱。技术是一次融资，并永久压低对应商品售价；不要忽略确认提示。

## 实际验证与边界

2026-10-12：66项EditMode测试通过，包含生活供给现金/库存守恒、价格政策、饮水保护、180秒缺供恢复、紧急水额度、暂停/死亡、旧工资归属、固定暴动目标、工作台预约与拆除（含完成堵出口不重复返料）、采购预算及模式2迁移。默认新局由PrototypeDemoScenario用普通操作走到八项目标，不注入任何库存或现金；独立Windows运行也完成相同路线。

固定验收种子4271的路线约28分钟游戏时间，木工14批、拆解1批、工具装配1把、首期工资50钱、消耗食物15份，结束现金261.65。路线售出工具80、纺织50和金属100钱技术，保留木料技术。这个结果验证的是操作可达性，不能证明常规生产已达到60—90分钟扩区节奏。仅靠一个居民做木板的早期尝试，额外运行两小时后只有72.85钱，提示常规利润和空间压力仍需后续调校；本轮未改S5价格、来料和工资数值。
