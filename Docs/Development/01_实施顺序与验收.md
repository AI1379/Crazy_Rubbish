# 实施顺序与验收

更新：2026-10-08，依S4重排，覆盖完整比赛范围，不重承诺历史17天工期。

## 基线

Unity 2022.3.62f3、Git/LFS、Core/Prototype/Editor/Test程序集及M1拾取—木工—出售已存在。M1数值为历史实验值；本轮推进M2起步切片，当前完成度及简化见[说明](04_M2起步说明.md)。

M2a起步功能已接入并通过32项规则测试、Windows构建与独立运行验收，首次5人50钱工资闭环成立。加权容量和满地堆高基础一并落地。M2b及后续仍需实体物流、生活消费、工具和机器耐久等系统；这不代表完整比赛版完成。

## 阶段

| 阶段 | 目标 | 验收 |
|---|---|---|
| M2a 起步 | 新版木工、固定物资、工作台、拆解、发电、认可招募、居民木工、钱包、首次手动工资 | 0钱地面起步；燃料耗尽停；招募不免工资；暂停统一冻结 |
| M2b 基础经营 | 加权容量、实际搬运、生活消费/衣物清洁、完整工资、住房幸福度 | 双方现金与库存守恒，缺钱/缺货区分，生产保护饮水 |
| M3 物流能源 | 网格建造旋转移动、路径、电线、独立接口、传送带、电动/自动木工和维护 | 堵塞/缺电/耐久可恢复，岗位不瞬移，移拆库存守恒 |
| M4 多产线 | 三地点塑料、两地点金属、种植、工具损耗回收、实际堆高、填埋 | 材质不混、人工/机器加成分开、无隐藏队列 |
| M5 居民经营 | 收费/免费/补贴、租金服务、奖金、技术售卖、幸福度暴动与承诺 | 账单分母不变、双原因分别恢复、承诺不重计时 |
| M6 完整流程 | 两次扩区、跨区物流、第三地区勘探开采、返程、倾倒结局及存档 | 无注入资源从新局到结局，三分支与存档恢复 |
| M7 完整试玩 | 第一区60—90分钟、整局3—4小时、多人口经济、提示素材与构建 | 无倾倒可通关，时间/空间/资金成立，目标平台验证 |

这是实施顺序，不是删减比赛范围。后半局待设计时先推进不依赖这些决策的前期闭环。

库存及批量原子性、多产物不丢失、燃料及灰渣余数、暂停/倍速/重开、工资账务、容量边界、缺工具/人员/输出恢复须持续回归。旧M1测试不能代替新版平衡验收。
