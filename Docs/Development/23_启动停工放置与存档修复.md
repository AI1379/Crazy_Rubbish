# 启动、停工、放置与存档修复（2026-10-16）

实施范围：用户选择可玩性检查中的1A、2A、3A、5A。未实施全局产线诊断、自动化建造工具或三区主线。

启动明确进入标题菜单，选择男主／女主后建立会话。标题菜单不能用Esc跳过；经营中打开菜单暂停模拟并保留当前进度，可以返回经营；结局状态不允许继续模拟。

设施停工释放操作工，保留在制批次和进度，维护人员继续工作。人工指定的停工岗位不再锁死其他工作；重新运行后可以再次分配人员。关闭接口后停止与机器和上游输送的物品交互。旧存档中已停工却占用人员的状态在读取时整理，存档格式不变。

建造预览和实际建设调用同一套检查，包括地形、接收点、占用、物品、操作侧、科技、材料、人员和水源。显示机器轮廓、占地、操作侧及失败原因；只预览不会消耗材料或占用水源。移动设施同样显示预览，失败后保留移动模式，成功或取消才退出。

设置与标题菜单增加存档列表，区分手动档和自动档，显示保存时间、区域、经营时长、角色和现金。读取选中的文件，不再仅能读取最近一份；无法解析或不兼容的条目不可读取，原文件保留。

开始新游戏、换档和退出前，未保存的进度可选择保存并继续、不保存继续、取消。检查覆盖暂停时建设和库存变化；保存失败保持当前会话。保存并读取同一手动档时会另存当前进度，保留被选中的旧档。存档列表和选择窗口打开时模拟不推进，关闭后沿用原暂停与倍速状态；主菜单保留当前会话，返回经营无需另行保存。

沿用原存档schema、版本、目录及三槽自动存档，失败结局不会覆盖失败前手动存档。保留旧Demo的独立目录。本机以Unity2022.3.22f1验证，正式工程目标仍为2022.3.62f3。

验证：增加停工与接口、预览无副作用、移动失败和旧档整理的规则测试；实际运行覆盖启动角色选择、建造移动、存档列表、保护被选旧档、取消离开、保存后新游戏、无效文件读取失败以及窗口计时。最终结果见交付检查报告。

实测结果：177项规则测试全部通过，Windows构建与场景验证通过。1280×800与1920×1080的实际启动角色选择、移动预览、存档列表、旧档保留、取消离开、保存失败保护、无效档保护及原有菜单／框选／取水／零资金开局检查均通过。另修正了新游戏首帧界面缩放尚未生效的问题。测试使用独立目录，不接触玩家个人存档。
