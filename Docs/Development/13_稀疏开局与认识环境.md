# 稀疏开局与认识环境

更新：2026-10-14。用户确认保留旧仓库和旧住房，其余内容逐步出现。本轮替换开局铺满物品与设施幽灵图的试玩表现。

## 开局与来料

- 开局地面物品为空，保留主角、落料洞、投弃洞、旧仓库和旧住房。生产地点未建成时不显示；从建造面板选择地点，才显示临时建设预览。社区路灯在首次发电后显示。四处地标保留简短名称。
- 落料洞位于(7,13)，物资优先落入下方(7,11)附近的原8×6来料区。投弃洞仍位于原x2—3、y20—21，入口(4,20)。旧仓库、旧住房和产权范围沿用原坐标。
- 新局开始运行2秒后先到一把可用手锯；首批每7秒到一种物资，限手锯、食物、水、废木料、紧固件这五类。读开局介绍时不运行时间。
- 木工台建成后，每12秒加入首批钢铁零件、螺丝刀、旧切割装置、追加木料和紧固件。实际生产一批后继续到达发电组件、电线、剩余钢铁零件和木料；首次发电后，每24秒逐项加入其他保证回收物与工具。
- 上述批次是原有一次性保障物资的分批投放，数量不增加，不存入背包或仓库，不因教程推进而奖励。所有阶段看实际建设、生产与发电事实；跳过教程仍按相同规则运行。首次发电前的持续来料限少量木料和食物／水，之后恢复原多类别随机来料。
- 新局由`PrototypeGame`和场景预览显式使用渐进开局。原完整库存构造仍供隔离的经营规则测试使用；新的端到端测试使用实际渐进开局。

## 认识对象与首次教学

欢迎页后依次介绍落料洞、投弃洞、仓库、住房，展示真实图标、名称、用途和金色地图位置。四处看完再进入原实际操作任务；没有员工工资的隐形豁免。

新物品或机制首次出现时，知识卡代替当前任务卡，解释手锯、生活物资、木料、木工、木板、零件、旧设备、工作台、拆解、发电、居民、工资和工具补充。卡片关闭后回到当前任务；已读记录随存档保存。介绍与任务进度各自记录，介绍本身不解锁科技、不制造资源。

左键短按任何地面物品，随时查看与地图相同的图标、名称和用途，并可前往／拾取指定物品。短按设施查看操作，短按两个洞查看用途。普通用途卡不暂停游戏；仍可按空格暂停。当前未实现的后续产线在说明中明确标注，不把旧设备图标冒充已建成机器。

工作台与发电机的建造卡在实际取得对应解锁材料后出现；设施的生产按钮在建成后出现。基础木工、拆解知识沿用策划的开局知识，不把自由玩法锁在教程里。

## 鼠标与投弃

左键按住拖动平移地图，中键拖动继续可用；使用屏幕像素位移，暂停时也能拖动。超过6像素视为拖动，释放不执行点击／行走。面板上的按压不开始地图拖动；右键行走、滚轮缩放保留。

投弃洞现在可实际使用：短按洞查看，前往入口，切换背包物品，点丢弃后再次确认才投下一份。遵守半秒交互、距离、暂停与工具预约规则；取消交互不扣物。丢弃数量以容量刻度累计并存档。教程不要求投弃，去向与后续结局不提前揭露；完整结局判定仍未接入。

## 验证

104项EditMode测试通过，包括空地开局、首批五类物品、保证物资总量守恒、暂停与存档不重复发放、旧档兼容、完整渐进教程路线、投弃取消／完成以及介绍记录独立复制。新增回归覆盖空闲居民读档后仍无搬运任务，修复Unity将空任务记录反序列化成空对象造成的运行异常。
