# 按需界面与场景检查

更新：2026-10-14。延续首区 Demo，本轮将常驻管理控制台改为覆盖在世界画面上的可关闭面板。

## 显示规则

- 世界相机使用完整窗口。面板开关不改变相机位置、缩放或视口；开局镜头靠近首区活动范围，仍可滚轮缩放、中键拖动。
- 仅资源摘要、时间控制与底部五个入口常驻。右侧管理面板、木工操作面板默认关闭。保存、读取、新局与阶段目标位于菜单中。
- 地图中的设施名、区域名、人物名和物品数量标签全部隐藏，放大也不重新出现。旧场景标签对象保留为禁用状态，保持场景引用稳定。
- 区域边框默认隐藏；打开建造页或切换“区域”时显示。选中设施只显示对应设施的作业范围，教程定位保留无文字的目标框。
- 指针在同一对象停留 0.4 秒后显示不拦截点击的小浮窗；移开、切换对象、滚动、拖动或打开菜单时隐藏。已在操作面板中查看的设施不再重复弹出悬停信息。
- 浮窗覆盖生产设施、仓库、住房、洞、路灯、居民、主角及地面物资；地面混合物资显示前三类及剩余种类数。完整物品目录仍从仓库页查看与指定拾取。
- 缺供、欠薪、暴动、工具耐久过低使用可点击的警报入口，正常时隐藏。普通操作结果约 4.5 秒后消失；存读档反馈仍保留在菜单中。
- 新手准备状态保留小型引导卡，明确说明时间暂停，并提供“开始教程”与“自由经营”；不会在关闭大面板后让玩家无提示地卡在准备阶段。

## 操作

| 输入 | 行为 |
|---|---|
| 左键设施 | 查看该设施专属面板，不直接下达走路指令 |
| 左键仓库／住房／居民 | 打开物资或人员管理 |
| 左键空地／右键地图 | 前往指定位置；右键设施前往其可达操作点 |
| 设施面板“前往作业点” | 前往设施正面；投料与生产继续遵守距离与物资规则 |
| B／P／I／H | 打开或再次按键收起建造、人员、仓库、教程 |
| Esc | 先关闭交易确认或面板，再取消当前行动，最后进入菜单；菜单中再次按 Esc 返回 |
| WASD／E／Shift+E／Q／F | 移动、附近交互、整堆拾取、入库、木工作业 |
| 空格／1／2／3 | 暂停与倍速 |

面板底板拦截鼠标。滚轮和中键在面板范围内不会操作背后的地图。普通面板不暂停经营；原有菜单、准备教程与暂停规则继续生效。

## 实现与兼容

- `PrototypeHudPanels.cs`：面板状态、设施专属操作、快捷入口、引导卡与通知。
- `PrototypeHudLayout.cs`、`PrototypeHud.cs`：布局版本 8；保留现有命令与数据绑定，教程可定位到已移动的木工和建设按钮。
- `PrototypeWorldInspection.cs`：设施命中、左／右键操作、延迟悬停与区域覆盖层。
- `PrototypeWorld.cs`：场景显示版本 4；旧美术已迁移的场景不会再次执行白盒素材替换。
- `PrototypeGame.cs`：Esc 优先级、面板快捷键、通知版本与新局／读档重置。存档格式和生产经济规则不变。
- `PrototypeTutorial.cs`：更新界面操作文案，步骤达成条件不变。
