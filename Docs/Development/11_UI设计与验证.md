# 工坊 UI 改造

更新：2026-10-14。本轮调整 Unity uGUI 界面的视觉、信息层级与导航，玩法基线沿用 S5。

后续已将常驻侧栏和木工底栏改为按需打开的面板，并隐藏所有场景文字，当前操作与验证见[按需界面与场景检查](12_按需界面与场景检查.md)。本页保留第一轮视觉改造记录。

## 设计与布局

参考 [Factorio 的界面分组设计](https://www.factorio.com/blog/post/fff-212)、[物品槽与页签设计](https://www.factorio.com/blog/post/fff-289)，以及 [RimWorld 的经营界面](https://store.steampowered.com/app/294100/RimWorld/)。界面采用石墨灰工业面板、浅色正文、琥珀色主要操作与选中标记、绿色正常状态、珊瑚红异常提示。所有图标继续使用项目已导入的美术，没有引入其他游戏的图片资产。

- 顶栏：品牌、经营现金、电力、人口、食物、水、时间和暂停倍速；保存、读取、目标菜单集中在右端。
- 当前目标：独立窄条，保持教程、工资和缺供提示的可见性。
- 右栏：现场、人员、仓库、教程四页。工资与缺供状态固定在底部；各页具有可拖动滚动条。
- 现场：建设设施显示图像、用途与建造入口；固定的“建设／搬运／装配／交易”快捷导航可跳转到对应工序。
- 人员：供应政策、生活账目和居民名册分组；居民卡片显示造型、钱包、活动与饮食状态。
- 仓库：图标、物品名称、背包／仓库数量和四项操作分层显示；保留仅持有／全部物品切换、预约数量及容量条。
- 底栏：交互、入库、木工建设、配方及作业按钮；其次是生产进度、配方和操作反馈。建造完成与预约状态显示明确文案。
- 菜单：八个阶段目标改成双列进度卡片，保留保存／读取反馈；菜单遮罩拦截点击，避免穿透到游戏操作。

界面以 1600×900 为参考，按宽度缩放。地图视口与界面共用 `PrototypeHud` 的边距常量；参考高度 900 下地图视口由原先约 534 高提高到 614，高度增加约 15%。兼容原有暂停、倍速、教程按钮定位和主角操作。

## 实现位置

- `Assets/_Game/Scripts/Prototype/PrototypeHudLayout.cs`：布局、资源栏、物品与居民卡片、菜单及公共尺寸。
- `Assets/_Game/Scripts/Prototype/PrototypeHud.cs`：数据刷新、按钮绑定、教程排版、滚动条和控件样式。
- `Assets/_Game/Scripts/Prototype/PrototypeWorld.cs`：世界相机使用同一组 UI 边距。
- `Assets/_Game/Scripts/Prototype/PrototypeSmokeRunner.cs`：独立运行时验证完整教程、列表滚动、页签及场景覆盖边界，并输出截图。

场景中保存完整布局，编辑模式可见。布局版本升级时重建旧界面；缺少新菜单引用时也会迁移。中文字体已重新生成子集，沿用现有 Noto Sans SC 衍生字体及 OFL 许可。

## 验证记录

- 93 项 EditMode 测试通过。Windows 开发试玩版已重新构建到 `Builds/Windows/CrazyRubbish.exe`。
- 1280×800 与 1920×1080 独立运行均通过：完整教程、首区八项目标、实际物资与生活消费、首次发薪、工具装配、存档恢复与重开；两种分辨率均无运行异常。
- 新增运行检查验证首次进入现场页从顶部开始、交易快捷导航、居民卡片人数、仓库完整目录最后一行可达、顶部库存为真实数值，以及管理面板／操作栏不遮挡地图视口。
- 实际 Windows 窗口点击检查通过：开始试玩、管理页签、交易快捷导航、全部物品切换与滚动条拖动。修复了旧场景缺少新增控件引用以及首次打开现场页停在列表中段的问题。
- 已检查初始界面、现场设施、交易、持有物资、完整目录底部、居民名册、教程、菜单与阶段结算截图。截图位于 `Artifacts/UIRefresh/UI-1280*.png` 和 `UI-1920*.png`；改造前画面保存在 `Artifacts/UIRefresh/Before-1280.png`。运行报告为 `TestResults/ui-1280.json` 与 `ui-1920.json`。

场景保存为布局版本 7。编辑器自动迁移仍沿用“场景原本有未保存修改时只标脏、不自动保存”的规则。当前布局以桌面横屏为目标，其他窗口比例尚未全面验证。
