# 产线状态与风险提示（2026-10-17）

实施范围：用户选择可玩性检查4A、6A。现有生产、生活、发薪、暴动及存档规则沿用，本轮补充信息与定位操作。

## 实时设施信息

右键设施的卡片与管理栏设施页每0.25秒按真实状态更新：当前配方与下一批配方、阶段进度、输入含在制和输出容量、原料缺额、操作工已安排/到岗/需求、实际可选工具与耐久、当前用电需求与供电比例、维护人员及操作侧。采水设施同时显示共用水源预算。

停机原因按实际条件区分：待建成、手动停工、耐久等待恢复、原料不足或品质不符、输出空间不足、水源补充中、工具缺失、操作工未到、无供电、无太阳灯以及人工阶段受暴动影响。已预留的在制原料不再次报缺；机器部分供电显示减速，自动阶段不因暴动报人工停工。人工阶段的工具读数按实际选用规则显示，机器阶段不要求工人到岗。

刷新原有文字与取货按钮，新增产物和数量变化无需重开菜单。保留窗口拖动位置和正文滚动位置；文字增长时后续按钮顺移，窗口仍受屏幕边界约束。目标设备不存在时安全收起菜单。

## 预警与入口

顶部通知下方最多显示4个提醒入口。超过4类时保留前三类，第四个入口展开全部提醒，避免遮挡过多地图。严重生活缺额使用红色，其余使用棕黄色。提醒不自动暂停或修改经营政策。

| 类型 | 条件与显示 | 点击效果 |
|---|---|---|
| 饮水/食物已不足 | 存在实际未满足生活需求，显示受影响人数；含主角 | 镜头定位缺额者，打开居民管理 |
| 饮水/食物库存偏低 | 仓库覆盖不足1轮，区别于实际缺额 | 优先定位地面可用物品，其次相关生产设施，打开居民管理 |
| 发薪将至 | 下一次发薪前120游戏秒开始提示 | 打开居民管理，显示剩余时间与预计应付金额 |
| 已到期欠薪 | 欠薪余额大于0；与发薪提醒合为一类 | 打开居民管理，仍需手动发薪 |
| 住房供电不足 | 实际有入住者且供电低于50%的住房，按住房去重 | 定位住房并打开设施实时卡 |
| 多处停机 | 至少3台启用、已建成、已选配方的设备受阻；手动停工不计 | 展示最多12台受阻设备及原因，点击定位 |

优先顺序为实际缺水、实际缺食、已欠薪、发薪将至、库存偏低、住房供电、批量停机。水、食物、工资均按类别汇总，避免为每个居民或每台机器重复弹窗。工资预计值按当前存活员工与现行每人周期工资计算，主角不计工资；招募和死亡会实时改变预计值。

## 库存覆盖口径

底栏常驻饮水/食物仓库覆盖轮数、下次发薪倒计时与预计工资。覆盖轮数=(仓库可用份数－当前未满足份数)/存活总人口，最低为0；一轮为每人一份，正常饮食周期为300游戏秒。它不是死亡倒计时，也不按仓库外库存或可能产出来料作乐观估计。

背包、现场原料、设备在制品与个人外购不计入仓库覆盖。外购可能满足生活，因此库存偏低不能标成已经饥渴；实际不足人数单独读取生活欠额。提醒点击只移动镜头/打开界面，不指挥人物、不购买物品、不自动改变工作，也不推进游戏时间。

主菜单、结局菜单与存档窗口内隐藏提醒。保留原暴动窗口与倒计时，不透露隐藏欠薪累计阈值、死亡阈值或下层信息。新增提示不写入存档，不改变schema。
