# 建设搜索与生产查阅（2026-10-18）

建设目录新增搜索框，按设施名称、设施标识和建材名称筛选，忽略英文大小写及首尾空格。默认只显示当前区域已解锁设施，可切换查看未解锁设施。未解锁条目只能查阅占地、人手、建材和科技条件，不能越过原规则建设。搜索实时更新结果但不重建输入框，保留输入焦点；科技解锁或区域变化时自动刷新结果，保留搜索文字及阅读位置。无结果时提供清空或切换范围的提示。

输入搜索文字时，WASD、B、I、R、数字、空格等经营快捷键暂不响应，经营及已有任务继续。Esc先结束输入，再按既有顺序关闭界面。鼠标仍可使用倍速或暂停按钮。

库存物品右键菜单新增“查看获取途径 / 制作方法”。显示查询时可用的仓库、背包、地面、设施输出数量，以及目录中记载的采购、初始区域物资和产出配方。可以定位已开放地面的库存、定位已有设施产物，并逐层查看配方投入及附件的来源。统计不包含已预约数量，不保证未来垃圾输入，也不补发初始物资。

配方卡从现有配置读取制作设施、投入产出、各阶段时长、机器负载、工具损耗、附件、科技和区域要求，并标明淡水品质、光照、实例条件、采掘锚点及返程特殊操作。混合垃圾和封装物的实际内容以实例为准。总装的舱保存在平台专用槽，试车更新同一舱；查阅不能代替登舱确认。

设施菜单和详细设置新增“查找缺料 / 制作方法”，从当前配方和实际缺额进入查询。科技条目可点击查阅前置科技、缺少的必需材料和任选材料条件；材料须实际取得才解锁。所有查阅和定位均不自动搬运、采购、建设、换配方或推进时间。

库存页物品已被取走时，点击“拾1”改为中文提示“物品已被取走”，保留经营进度。没有修改经济、配方数值、科技条件、地图和存档格式。长局平衡仍待专项试玩。

验证结果：219项规则回归全部通过。Windows构建及1280×800、1920×1080实际运行回归通过；检查了建设检索与配方卡截图。运行检查覆盖中文与英文大小写检索、按建材检索、无结果提示、输入焦点保持、未解锁设施仅查阅、物品与配方跳转、附件和区域条件、浏览不修改台账、设施缺料入口和失效拾取提示。原有启动、存档、零资金前期、自动化及返程通关回归保留并通过。目标Unity版本仍为2022.3.62f3，本机以2022.3.22f1验证。
