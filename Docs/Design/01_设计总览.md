# 设计总览

来源：S1 全文、S2。正式名称、发布平台、美术风格、单局时长、团队分工与重新估算的工期均待定。

## 主题与体验

2D 俯视垃圾回收与基建经营游戏，比赛主题为“涌现”。上层工人意外坠入中层，借助垃圾处理知识组织居民发展生产，希望返回上层。垃圾既是文明发展所需资源，也不断挤占场地。

玩家经历亲自手工劳动、居民协作、半自动化和自动生产环节。易处理垃圾与耗时耗人工的塑料争夺处理能力；难处理垃圾堆积降低附近人工效率，使清理更慢。玩家可改善产线，也可向通往下层的洞倾倒，承担隐藏后果。

## 核心循环与开局

接收垃圾 → 拾取与加工 → 获得材料和产品 → 建设、安排居民、出售 → 改善物流与能源 → 提升处理能力 → 管理新增垃圾与堆积压力 → 完成返回目标或触发失败。

开局顺序：主角移动拾取工具和垃圾 → 用废木料、回收连接件搭建木工台与拆解台 → 手工加工 → 用回收部件组装简陋火力发电机 → 补充废木料发电 → 获得居民认可 → 招募首批居民。首批仅免招募费；工资在当前比赛范围延期。必须验证起步材料与工具能获得，避免先制造工具才能制造首个工具的死锁。

## 必须保持的全局规则

- 露天堆积与固定垃圾堆按占地影响附近人工效率；仓库中的垃圾不计压力。加工中的物料在设备内部，不额外占地。
- 建设需要材料和足够空闲人员；暂停时可以规划，暂停期间放置的设施恢复运行后建成。
- 移动／拆除设备时内部物品先转仓库，装不下的留在旧址，阻止建设并计入压力。拆除返还建造材料；残留物需要运输才能入库。
- 缺原料、工具、人员、输出空间或电力时停止相关工作；条件恢复后继续。生产工人在停工时成为空闲工人，恢复后通过补位取得人员。
- 饮水和清洗共享水库存。玩家设定饮水保留量，清洗不能动用保留部分；居民自动领用，不另加生活配送流程。
- 居民死亡减少人口，游戏继续。全员死亡、主角需求和岗位善后未定。
- 同一工作地点可以切换已确认配方。解锁科技与建造设备是不同步骤；解锁不免除建造材料。
- 塑料握柄用于制作新工具，不能给旧工具换柄；只提高实际使用该工具的人工工序，不提高机器速度。
- 发电机补充燃料后自行运行，无需持续操作人员；燃料仍需运输，耗尽停止。
- 所有玩法计时使用统一游戏时间，暂停和加速一致生效。

## 倾倒与结局

洞一直可用，玩家可选择倾倒种类并停止；主角、工人和传送带均可运送。累计倾倒记录与下层发展对玩家隐藏；累计达到阈值后延迟触发入侵剧情，不制作战斗或可玩下层地图。

| 结局 | 已确认条件 |
|---|---|
| 好结局 | 从未倾倒且成功返回上层 |
| 普通结局 | 倾倒过少量、未达到入侵阈值且成功返回 |
| 坏结局 | 达到阈值，延迟后下层入侵，中层覆灭 |

达到阈值、入侵尚未发生时返回的判定待定。存档必须保存倾倒记录、是否已触发阈值、延迟计时等会影响结局的状态。结局后返回首页，可重开，也能继续读取旧存档。

## 延期与阶段未定

工资奖金、幸福度暴动承诺、市场波动与出售技术、住房路灯、完整供电优先级、多地区、勘探开采、机器维护、复杂火电、完整填埋堆肥沼气体系、复杂传送带节点、完整 CG 延期。工具耐久的新增表述与延期的机器耐久不同，见差异清单。

太阳灯种植已有方向，但作物、种子、材料、供水供电、人员与制作阶段未定。新增生活需求不会自动恢复延期的工资与暴动系统。原 17 天排期需按新范围重新估算。
