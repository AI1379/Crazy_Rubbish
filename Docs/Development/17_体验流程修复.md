# 体验流程修复

更新：2026-10-17。沿用10月11日v1数值基线、模式5存档和现有自由建设／电动产线。

## 经营与开局

- 修复居民处于目标格内但偏离格心时，空寻路结果使取货永久等待的问题。按原移速走完剩余距离，旧档空路径同样可恢复，不瞬移、不跳过交接或复制货物。
- 新手启动储备调整为食物4、饮水8；第一处木工只先备木料4、紧固件2。后续生产和拆解用到时再收集；保障物资总量、背包容量、工资和生活消耗规则不变。
- 最后一课默认继续生产并收集、出售多余的金属原料、纺织等回收物，每类保留4份。操作仍需实际拾取和入库。技术融资通过单独入口选择及确认，不再成为默认下一步。
- 缺工具、原料、操作工和停产请求提供恢复操作；工人配送、配方切换、输出堵塞、机器维护和供电问题分别说明。

## 采购与交易

- B页顶部新增“建材采购／查看缺料”，设施面板新增“建材／采购”。按分类查看物资，选择每项1／5／10份后逐项购买；建设专页列出未预约可用库存和缺口，并可按每项实际缺口补货，备齐即停止该项购买。
- 采购沿用真实进价和现有满仓落地规则，展示现金、欠薪和下期工资预算。灰色电动设施按钮补充解锁材料说明。
- 仓库详情支持出售1份、5份或全部可用物品，显示当前单价与整批预计收入。预估计入动态价格、工具耐久、预约库存及饮水保护量，不扣款、不修改库存和行情。

## 自动化、阅读与恢复

- 完成原12课后，可继续自动化入门；H页也可重新进入。依次引导机器建设、接线并加工第一批、建立仓库与机器之间的输送循环，以3批加工和20件输送为可见目标。
- 自动化引导使用普通建造、采购、启停、接口和铺带入口，不自动注入材料或资金。继续／收起偏好保存在原存档中，旧档缺省不强制开始。
- 自动出现的新机制说明移至右侧，当前任务卡保留在左侧；手动查看物品和最初环境介绍保留原操作。
- 菜单支持自适应／标准／大号界面，按窗口宽高留出完整面板空间。
- “继续存档”改为分页列表，可见保存时间、游戏时钟、现金、人数和教程进度，可选具体回退点；保留最近有效存档自动回退能力。
- 进行中的会话选择新游戏时，先展示当前进度，并提供保存后开始、直接开始和返回。保存失败不会重置当前会话。

## 验证

新增回归覆盖同格寻路、旧档空路径恢复、交易预估守恒、饮水与预约保护、建设材料统计、无关电线不能跳过供电教学、不出售技术的新局路线及引导状态存档。

同种子4271的正常渐进开局，首处木工由275.7秒提前到115.4秒，入库操作由10次减至4次（模拟时间，不含阅读与点击耗时）。不出售技术的完整教学路线在56.4分钟达到200.68钱，完成41批生产；额外种子17、91的纯逻辑复测也能完成，分别达到204.98和200.72钱。

开发包1280×800、正式包1920×1080和正式包无图形模式均通过实际采购、按缺口补货、批量出售预估、选档恢复、新游戏确认、原12课、自由建设与完整电动产线验收。三条路线均完成3批电动加工、26件接口交付，存在实际维护且存读档续跑一致。采购、存档、物品栏、自动化任务卡和设施面板截图已检查，并通过独立程序实际点击检查菜单缩放、采购入口和Esc关闭。

180项完整Unity EditMode回归全部通过，报告保存于 `TestResults/Experience/full.xml`。独立程序报告与截图在 `Artifacts/ExperienceFix/final-*`，普通／正式试玩程序在 `Builds/Windows` 和 `Builds/WindowsRelease`。
