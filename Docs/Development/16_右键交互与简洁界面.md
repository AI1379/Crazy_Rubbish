# 右键交互与简洁界面

本轮调整经营界面，地图、产线、经济与存档规则沿用现行版本。

## 操作

- 右侧管理面板默认收起，腾出的宽度用于显示地图。顶部“管理”或 Tab 展开/收起；B 直达建设，I 直达库存。
- 右键地面垃圾：查看该位置各堆的具体物品和数量、走近、选择拾取。拾取仍需满足距离、背包容量和工作状态要求；不会远程取物。
- 右键设施：走到操作侧、投料、主角劳动、开停机、取出成品、移动。配方、工人、过滤器、接口和拆售操作通过“详细设置”进入原有设施面板。同格输送带/接口等设施可在菜单选择。
- 右键库存物品名称或图标所在行：查找地面同类物品、按现有规则购买或出售。
- 右键洞口：走近与倾倒设置；右键居民：查看状态并进入居民管理；右键空地：移动、建设或土地管理。
- 左键设施只选中目标，不强制展开右栏；E 拾取、Q 投料、F 主角劳动保留。建设或移动预览中右键仍取消放置。
- Esc 依次关闭右键菜单、取消放置、收起管理栏，最后打开主菜单。点击菜单外关闭菜单，该次地图点击不执行移动或建设。
- 右键菜单不会暂停经营，长物品清单可滚动；菜单在屏幕边缘自动调整位置。工资、暴动和生存提示仍保留。

仓库详情使用正常的仓储容量摘要；无限容量显示“不限”，避免数字撑破界面。镜头根据当前可见地图宽度约束边缘，收起侧栏后不会露出大片地图外空白。

## 验证

正式工程保持 Unity 2022.3.62f3；本机使用已安装的 Unity 2022.3.22f1 验证与构建。交付时记录现有编辑器测试结果，以及1280×800、1920×1080下的运行检查、右键库存事件、设施开停机、详细设置、Esc、菜单边界与点击遮挡检查。

## 范围

当前可玩范围仍为前两区，三区与返程完整流程沿用此前实现状态。本轮不改变地区、科技、资源或胜负条件。
