喂——出来 0.1.0 · Windows 64位

请完整解压下载包，再运行 CrazyRubbish.exe。不要把程序单独移出目录；同目录的 CrazyRubbish_Data、MonoBleedingEdge、UnityPlayer.dll 都是运行所需文件。

开始：在标题菜单选择男主或女主。开始前可点“操作说明”，进入游戏后也可在底部齿轮打开。具体教学在右上角倍速条下方，可收起或展开。

目标：回收垃圾、建设产线、保障居民生活并支付工资，逐步开放三个区域，重建升降舱返回上层。

开局：先收好食物、水和手锯；手工加工木板，搭起发电机、投入燃料并接通住房或路灯；获得认可后招募居民。优先保障饮水和工资，逐段投入生活产线。

操作速查
WASD / 左键短按空地：主角移动
左键拖动：移动地图；滚轮：缩放
右键短按：物品、设施菜单；右键拖动：框选
选中人物后右键地面：命令移动；到达后待命，在人物菜单选择“恢复工作”返回自动工作
E：拾取；Q：入库/投料；F：主角参加所选设施工作
B：建设；I：库存；Tab：管理；R：旋转；右键/Esc：取消放置或关闭当前菜单
空格：暂停/继续；1/2/3：选择速度
M：全图；Home：回到主角

在设施菜单选择配方、查看缺料和工具；在居民页手动发工资。部分设备需要专职维护，机器与仓库间也需要工人或传送带搬运。建设时请给操作侧留出通路。

底部齿轮提供保存、读取、主菜单和退出。自动存档每5游戏分钟轮换3份；请在重要扩建、倾倒或返程前手动保存。读取或新游戏前可以保存当前进度。结局不覆盖失败前的手动档。

存档位于：
%USERPROFILE%\AppData\LocalLow\DefaultCompany\Crazy Rubbish\S6PlanSaves
解压新版本不会清除该目录。首版使用本地存档。

出现问题时，请记录标题菜单版本号、操作步骤及截图。若与进度有关，请保留对应存档；运行日志位于上面目录的上一级 Player.log。不要仅提供“打不开”或“卡住了”，尽量描述最后一次操作。

字体授权见 Font-OFL.txt。当前已知问题见“0.1.0_已知问题.txt”。


兼容旧版游戏与存档

初次启动标题页可选择“旧版游戏 / 存档”，进入原 main 版本并读取原 Saves 目录的进度。新版继续使用独立的 S6PlanSaves 目录；两种存档不能互相载入。旧版的格子背包与拖拽操作仍在旧版入口中。返回新版请重新启动程序。也可通过命令行参数 -legacyGame 直接启动旧版。
