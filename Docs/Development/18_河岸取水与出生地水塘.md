# 河岸取水与出生地水塘

地图版本6，在出生地原渗水点旁增加真实的小水塘，中心约(20,24)，带浅水岸边与深水中心。原人工取水(22,22)和一体机(22,21)的占地与操作侧保留为干岸，已有流程仍可使用。

## 取水

人工采水地点与采水净化一体机可以建在已开放地区的河流、湖泊或水塘岸边。设施至少一条占地边与水面相邻，不能只接触对角，也不能直接放进浅水、深水或未开放地区。普通设施的建设与通行规则不变，操作侧仍须可达。

右键水面可查看规则并选择已解锁的取水设施；建设预览会检查临水条件。取水设施菜单和详细面板显示可用取水预算、缓存与补水速度。

人工取水仍每批6升原水、30秒人工处理；原水必须过滤煮沸后饮用。一体机仍按原配方消耗燃料和滤材，6升原水产出5升饮用水，保持原有供电、耗时与维护规则。来源标记表示可进入这条净化流程，不表示水面可直接提供饮用水。

## 暂定预算

- 出生地小水塘沿用原水源：初始/上限12升，每分钟补充6升，共用一台取水设施；旧锚点和其他岸边位置共用此限制。
- 其他连通河湖水体：初始/上限120升，每分钟补充60升。可建多台设备，同一连通水体共用预算，不按岸边设备数量重复补水。
- 人工取水开工预约，完成扣除，取消释放预约。一体机开工即扣除，未完成取消只返还已采原水及未消耗材料；设备缓冲放不下时物品落在地面。重复取消不重复返还。
- 拆除不补满水源缓存；重新建造、扩区和读档保留缓存与预约。取水设备更换位置仍需拆除重建。

以上数值为本轮保守补值；其余生产和经济数值保持现行配置。

## 旧存档与地图

旧版设施、操作侧和地面物品如占用新水塘位置，会保留地基并绘制水上平台，原物品与设备位置不丢失。出生地旧取水设备保留绑定；其他地区旧渗水点保留原锚点与预算。主河网继续连通，出生地小水塘独立于河网。

使用既有地面与河水绘制方式，不新增外部美术依赖。工程目标Unity 2022.3.62f3，本机以2022.3.22f1验证与构建。
