# 自然洞室地图 · 2026-10-14

> 本文记录地形版本2。当前规模与新增岩体以[版本3扩展说明](13_洞室扩展与复杂地形.md)为准；本文数值用于保留历史。

本轮用户明确：地图边界用素材补齐，采用常见经营游戏的自然场地形式；玩家利用已开放地图的所有可用资源和地面；**保留付费扩张，开放范围按自然地形划分**。

地图现在由相连的不规则洞室组成。岩壁、碎石和渐暗岩层包围场地，移除旧矩形产权线；地面材质按自然斑块混合，未开放洞室较暗，入口有岩石阻隔。付费开放后入口阻隔消失，新洞室的地面、垃圾和水源一起可用。

## 实际规则

| 项目 | 当前实现 |
|---|---|
| 逻辑网格 | 86×32，网格用于放置和寻路，画面没有外层矩形边框 |
| 一区洞室 | 731格地面，包含原垃圾落点、社区和原324格建设地 |
| 二区洞室 | 700格地面，包含原36格垃圾落点及原432格建设地 |
| 三区轮廓 | 746格地面预留，完整三区玩法仍未开放 |
| 付费扩张 | 一区默认开放，二区仍支付200钱；不追加教程、时间或材料门槛 |
| 地面用途 | 已开放洞室的可用地面都能建设、摆放产线或存放物品；不是仅旧产权矩形可用 |
| 必须保留 | 洞口、固定垃圾落点、已存在设施、永久填埋地等按各自规则限制；固定落点可取料和通行 |
| 岩壁 | 不是可建设地面，角色、工人和物流寻路不能穿过 |
| 未开放洞室 | 不能行走、建造或提前取得物资；付费后固定物资只生成一次，旧来料不停止 |
| 垃圾溢出 | 搜索整个已开放洞室的真实可用地面，跳过岩壁、接收点和设施占地 |
| 资源提示 | 水源只在对应洞室开放后显示，避免把未来资源提示成当前可用资源 |
| 建造预览 | 检查设施全部占格；跨岩壁或未开放地面显示红色 |
| 旧S6存档 | 保留现金、物资、科技、工资、机器与区域；若人物处于新岩壁或未开放位置，迁至最近开放地面 |

731、700、746为洞室地面格数，不是最终剩余空地数；固定落点、社区设施、后续建筑和填埋仍会占用相应地面。

原始S6的 `land_rectangle` 保留为历史资料与兼容坐标，不再限制默认游戏的可用范围。运行时地形版本为2，由 `PlanTerrain` 统一定义；画面、可建设范围、行走与溢出使用同一地形掩码。原有建设坐标、接收点和净水设备锚点保持有效。

## 素材与编辑

新增 `Assets/_Game/Art/Cave/cave_rocks_atlas_v1.png`，由内置 image_gen 生成，实际1254×1254、真实透明RGBA。原PNG不改像素，由Unity分成四个627×627象限：岩脊、巨石堆、层状岩、碎石。Point采样、关闭mipmap、无压缩。原74张素材保持原样；全项目新增1张图集。

生成提示词、尺寸、透明度和SHA256见 `Docs/Art/CaveAtlasGenerationInfo.json`。工具为内置 image_gen，没有使用CLI/API替代。新图只用于岩壁与不可建设的外围；没有额外加入树木、生物、矿产或新的收集配方。

`PlanTerrain.cs`维护洞室轮廓，`PlanGameTerrain.cs`绘制岩壁、地面、入口和已开放水源，`CaveArtInstaller.cs`维护四个切片。编辑轮廓后需重新检查地面连通、旧坐标和建设占格；不能只改画面留下另一套矩形限制。
