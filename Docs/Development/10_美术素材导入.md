## 操作与复现

Unity Project 中展开 `Assets/_Game/Art/Delivery_20261013`。
图集左侧展开箭头后即可选择子精灵，Sprite Editor 可调整边缘和锚点。
菜单 `Crazy Rubbish → Art → Validate October 13 Delivery` 核对原图哈希、
导入参数、分辨率、精灵数量、切片、锚点及持久引用。
严格核验针对清单中的初始值；有意修改 Sprite Editor 校准值后，应同步更新清单再核验。

首次导入会自动应用清单参数，日常重导入保留已有 `.meta` 中的人工校准。
菜单 `Apply October 13 Delivery Import Settings` 会重新应用清单，覆盖手工切片或锚点；
用于明确需要恢复交付初始设置的情况。对应命令为：

```powershell
python Tools/ImportArtDelivery.py 'path/to/喂——出来游戏素材.zip'
.\Tools\Unity.ps1 -Action ArtImport
.\Tools\Unity.ps1 -Action ArtValidate
.\Tools\Unity.ps1 -Action ArtScene
```

Python 整理脚本依赖 Pillow；若目标已有内容不同的同名原文件，会停止而不是覆盖。
Unity 命令在本项目 Editor 关闭时运行。验证结果写入忽略的
`TestResults/art-delivery.json`，日志为 `Logs/artimport.log` 或 `Logs/artvalidate.log`。
所有新增 Assets 文件与目录连同 Unity 生成的 `.meta` 一起保留；PNG 已受现有 LFS 规则覆盖。

## 当前接入边界

Main 场景和 `M1Appearance.asset` 已使用本批美术：主角、四套居民、地面、仓库、住房、
洞口、路灯、木工、拆解、工作台、发电机、垃圾高低堆以及仓库物品图标均已接入。
原场景对象 ID、操作点和 UI 绑定保留；人物图层根据脚底位置排序，动作图层围绕接地锚点摇晃，
移动按实际方向切换四向，有携货时使用木箱搬运姿势，实际地面拾取时俯身，手工锯切时使用锯切姿势。
停止或暂停时停止摇晃，其他工序不套用锯切动作。居民造型按 ID 轮换，当前主角默认男主。

垃圾低高图统一可见宽度和底部中心，数量变化时保持同一格接地位置。
21 个已交付物品图标使用对应切片；其余物品复用本批最接近的图形，例如木柄复用木板、
工具工作端复用对应完整工具图，真实物品名和数量继续由界面显示，未新增未交付的物品贴图。

没有因画面更换而增加供电服务或改变碰撞、库存、配方及经济规则。
