# 设计总览 · S6

现行来源是桌面 2026-10-13 合并策划、全局数值与科技设计、食物与水 v1.1，版本 `balance-2026-10-13-food-water-v1.1`。完整设计仍包含三区域及返回上层；本轮默认游戏实现范围是一区和二区。

玩家在中层收集垃圾，建设固定配方的回收产线，给居民提供真实生活物资和工资。不可预知的来料随经营时间增加，占用地面并降低附近人工效率。科技通过实际取得材料瞬时免费解锁，建设仍支付实物并需要空闲人员。扩地只支付金钱，不由教程或游玩小时数锁定。

| 项目 | 现行规则 |
|---|---|
| 地图 | 完整方形250×250；前两区25333格可建设地面；连续干支流与桥面；岩脊及狭口划分付费地块；保留旧地面与付费扩张；三区未开放 |
| 一区开局 | 固定物资 246.5 容量，社区 6 床／80 仓容；主角从拾取、手工与供电开始 |
| 二区 | 200 钱购买；一次性固定物资、独立水源及新垃圾落点，旧区继续来料 |
| 产线 | 人工、机器、自然成熟、灯照生长分阶段；现场缓冲，实际运输 |
| 生活 | 每人每300秒食物1、水1；真实衣物、皂、抹布、扫帚与服务消费 |
| 工资 | 每600秒每员工10钱，手动支付；奖金只影响人工，下一发薪时刻到期 |
| 市场 | 固定买价、累计销售临时压价、600秒压力减半；出售知识永久最低价 |
| 风险 | 欠薪或低幸福度暴动；填埋永久占地；实际倾倒积累触发不可逆的下层入侵 |
| 保存 | 新版独立存档，不读取或改写历史 Demo 存档；结局不覆盖失败前手动档 |

数值明细由配置生成，见[资源设施](02_资源与设施目录.md)、[配方科技](03_首批产线与科技.md)。工期历史和旧 Demo 目标不作为当前开发完成承诺。

地形与付费扩张最新规则见[方形地图与连续河网](../Development/15_方形地图与连续河网.md)，已开放洞室的全部可用地面可使用，旧矩形只保留为历史坐标。


最新界面：[右键交互与简洁界面](../Development/16_右键交互与简洁界面.md)。右侧管理默认收起；右键物品和设施查看操作，Tab管理、B建设、I库存。


最新操作：[拖动地图与框选指挥](../Development/17_拖动地图与框选指挥.md)。左键拖图，右键拖框，选中人物后右键地面移动，人物菜单可恢复工作。


最新地图与取水：[河岸取水与出生地水塘](../Development/18_河岸取水与出生地水塘.md)。地图版本6，河岸可建取水设施，原出生地渗水点变为小水塘。


最新时间界面：[嵌入式时间控制条](../Development/19_嵌入式时间控制条.md)。顶栏右端紧凑图标、高亮当前状态，空格暂停／继续，1／2／3选速并恢复运行。


最新存档入口：[底部设置与存档菜单](../Development/20_底部设置与存档菜单.md)。下栏右端齿轮集中保存、读档和主菜单，管理入口一并移至下栏；顶栏保留状态和倍速。


最新菜单操作：[设施菜单拖动](../Development/21_设施菜单拖动.md)。左键拖动标题栏移动框内设施和右键菜单，正文仍可滚动，窗口限制在屏幕内。


最新稳定性修复：[启动、停工、放置与存档](../Development/23_启动停工放置与存档修复.md)。落实可玩性检查1A、2A、3A、5A，增加存档列表及离开前保存选择，保留原存档格式。


最新产线提示：[实时设施信息与风险提醒](../Development/24_产线状态与风险提示.md)。落实检查4A、6A，显示停机原因、食水覆盖与发薪倒计时，点击提醒可定位，保留菜单拖动与滚动。


最新自动化：[铺带、接口与运输反馈](../Development/25_自动化铺带接口与运输反馈.md)。落实检查7A，整段拖拽铺带、接口自动绑定与预览、流向和堵塞提示、实时人员任务；独立交叉按轴过货。


最新通关主线：[三区矿料与返程](../Development/26_三区矿料与返程通关.md)。沿用既定数值，接通矿点、持续采掘、唯一升降舱、试车、登舱、续档与好/普通结局。长期经济和整局人工节奏仍待专项试玩。
