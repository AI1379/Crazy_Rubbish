## 通用加工引擎

所有新增产线遵循同一套规则：

- 每台设施实例都有独立的现场输入、输出和工具槽。选择配方后，输入、输出缓冲按两批的容量设定；同时只做一批，排队的新配方等本批完成后再切换。
- 开工时预约整批原料，并选定所需工具（同族里先选效率高的，再选耐久高的）。按配方阶段依次进行：
  - 没有显式阶段的配方，依次走人工、机器、自然三个阶段；
  - 种植和堆肥使用JSON里的多段阶段，包括人工阶段、太阳灯照明生长和自然熟化。
- 最后一个阶段完成、并且输出放得下时，才一次性扣原料、结算工具磨损并产出。未完成的批次可以取消，原料全部释放；已完成待出料的批次不能再退原料。堆肥过了第一阶段再取消，会变成“未熟堆肥包”。
- 水按升计、肥皂按清洁单位计，配方用量带小数：
  - 不足一整件的部分记为现场余量，例如塑料清洗一次只用0.25升水；
  - 小数产物（污泥0.1、损坏针线回收0.25钢等）同样累计余量，满一件才出。
  - 余量随存档保存。
- 人工阶段：
  - 需要足够的操作人员在作业面；返程装配平台需要2人。
  - 效率沿用v1公式：工具、奖金、幸福度、欠薪、食水和局部堆高共同影响。
  - 主角可以亲自操作；居民按“自动填岗”或手动安排到岗。
- 机器阶段按电网的实际供电比推进，不足时降速而不减产。有专职维护的设施在人工和机器阶段都会磨损：每秒0.2，维护工每秒恢复0.4，耐久归零停机，恢复到20重新启动。暴动停止全部人工阶段。
- 居民会把输入从仓库或地面送到现场，把工具送进工具槽，再把产物运回仓库。设施可以加装输送接口，接口数量上限取自v1。
- 搬迁或拆除设施时：
  - 在制批次按规则释放或结算，库存、工具和附件返仓，仓库放不下的留在旧址；
  - 出售按建材采购价值的0.45，再乘以耐久系数。

本轮通过通用引擎接入的产线和设施：

| 方向 | 设施 |
|---|---|
| 塑料 | 人工分选、塑料预处理、塑料再加工；PET需要干燥组件、PET熔融组件、打包带模具等附件；自动塑料预处理与再加工；复合料处理及其自动版；旧塑料再识别 |
| 金属 | 金属原料处理（需夹钳和供电）、金属零件制造（需锉刀，工具钢部件另需夹钳）、自动结构零件、自动金属原料、自动工具部件、制线 |
| 生活 | 清洗地点（洗旧衣、抹布、可裁布、芽苗、碎玻璃）；工作台的补丁、修衣、裁布、缝衣、塑料柄工具、扫帚、纸箱 |
| 种植 | 小型种植地配合太阳灯：每盏灯照亮2格内的一块种植地，按灯的供电比生长；堆肥场、基质调配 |
| 翻修与机电 | 翻修测试台（诊断、修复电机和驱动）、机电组装台（电机、驱动、控制模块、发电组件、送料组件、绕组） |
| 其他 | 制浆、纸板压制、玻璃再加工、工艺水回用、压缩打包（20种压缩包，拆包退回原料和PET）、新仓库 |
| 第3区 | 地质勘探站、持续采掘机、选矿、矿料加工炉、陶瓷烧成、返程装配场、升降舱检修平台 |

工具损坏后按工具族变成对应的损坏工具（如损坏的扳手），可以在拆解地点回收。旧电机、旧驱动在生成时就固定了状态：可直接用、可修复或只能拆。第2区的固定件保证可修复，商店买到的也是可修复件。

## 科技与技术出售

49项科技都按“历史上首次取得”判定：

- 取得材料就解锁，包括采购；同时检查上级科技和所需地区，不收费、不消耗材料、没有研究时间。
- 设施的建造按钮显示具体还缺哪项条件。科技页只列出已经见过原料的条目，不提前透露更下层的信息。

技术出售改用v1的15组表格：

- 收入一次性到账，对应商品的所有来源都永久按最低价出售。
- 首区原有6组（木料、纺织、金属、工具、塑料、栽培）保留已确认的材料触发条件，同时也接受v1的科技条件。
- 旧存档里已出售的6组会自动迁移。

## 地区、跨区与第3区

- 地区按顺序购买：第2区200钱、第3区600钱，坐标取自v1。
  - 购买第2区后地图扩为52格宽；购买第3区后扩为86×32。
  - 产权地、垃圾区和建设区随之开放，固定来料落在新垃圾区。
  - 人员、电线和传送带可以直接跨区连通。
- 第2、3区各有独立的自然来料，乘以0.6和0.4的区域系数，并使用该区的类别权重与旧件模板。第3区旧件预算的15%是承重框架。
- 勘探与开采：
  - 地质勘探站一次勘探一处矿脉（铁、铜、陶土）；
  - 勘探后，采掘机必须完整建在该矿脉范围内，每条矿脉只能有一台；
  - 矿脉范围不允许其他建筑占用。矿源无限，自动采掘需要加装送料组件和控制模块。
- 返程：
  - 返程装配场制作五类总成；
  - 检修平台只能建在第3区旧检修竖井口，坐标(72,21)；
  - 依次进行总装、测试、主角登舱上升（爬升需要12电力）。上升期间主角不能移动。

## 生活、幸福度与暴动

- 每位居民的幸福度以70为基准。五种原因（无床位、住房缺电、缺照明、缺衣物、清洁不足）各自按v1的宽限时间、增长时间和上限扣分；原因解除后在180秒内恢复。
  - 照明：社区路灯或已通电的自建路灯，6格内算有照明。
  - 欠薪暴动与生活暴动分别记录、分别恢复。
- 衣物：
  - 新居民的衣物剩余70%，满额寿命4800秒；穿坏后变成旧衣服进仓库。
  - 换新衣时先在库存里按零售价购买；首期发薪前免费；没有库存时，个人可以外购。
- 清洁：
  - 取得清洗科技或干净抹布之后才启用。
  - 每600秒，每人消耗1个肥皂清洁单位；每4人消耗1块干净抹布（变成脏抹布）并磨损1把扫帚。
  - 首期发薪后，居民在保留4钱的前提下，向社区缴纳0.5钱的照明和清洁服务费。
- 生活暴动：
  - 幸福度低于25的人持续180秒，并且人数达到 `max(2, ceil(20%员工))` 时发生，这些人成为组织者；
  - 期限240秒，期间全部人工岗位停工；
  - 作出承诺后，组织者只去补充发电机燃料、收集衣物和清洁用品，不恢复普通生产；倒计时也不会重置；
  - 组织者的原因全部解除、幸福度回到40以上才平息；超时则主角死亡。
- 其他经营手段：
  - 奖金：每档每人2钱，效率+10%，最多3档；要求没有欠薪，持续到下一次计划发薪。
  - 房租：自建住房0—2钱，可调；买不起不形成欠租。
  - 休息：可选服务，1钱换600秒+5幸福度。
  - 工具：工作台可开启自动补制，缺少某一族工具的备件时，用库存的握柄和工作端安排制作。

## 能源与处置

- 集中火电：锅炉、汽轮机和冷凝设备的占地互相在12格以内即视为一套机组，一一配对。
  - 启动：锅炉要有燃料和8升循环水，并从公共电网取1电力运行20秒。
  - 运行：每套向电网提供15净输出；每分钟补水0.1升；锅炉按木料60秒、碎屑30秒耗燃料并产生灰渣。
  - 完全空载时不烧燃料。三台设备各需维护，任一停机则整站停止。
- 填埋：
  - 填埋区占2×2，容量80。操作人员每1秒人工掩埋1容量，可处置残渣、损坏工具和压缩包（压缩包按未压缩容量计）。
  - 掩埋是永久性的：填满后封场，不能拆除。
- 投弃洞与结局：
  - 洞不接受饮用水、工艺水和返程关键部件；压缩包按未压缩容量计入倾倒量。
  - 倾倒量首次达到2400容量时，开始600秒不可逆的入侵倒计时，到时为坏结局。
  - 主角乘升降舱抵达上层：倾倒量为0是好结局；有倾倒但入侵尚未发生是普通结局。
  - 结局画面之后可以新开局或读取存档。

## 操作

- **G键／底栏“产业”按钮**：打开产业面板，共四页——产线建造、科技、区域与结局、生活。
- **产线建造页**：按产线分组列出全部v1设施。点击后在地图放置，R旋转；未解锁的会说明原因。
- **点击已建成的通用设施**：打开统一的操作页，可以：
  - 选择配方、开始或停止；
  - 投入原料和工具、取出产物或输入；
  - 主角亲自操作或维护，安排或释放人员；
  - 取消批次、安装附件、启停集中火电。
- **原有功能**：顶部的搬迁、拆除、出售和新增接口按钮保持不变。
- **地图**：显示已购地区的边界、矿脉的勘探状态和检修竖井位置。

## 工程简化（需要后续确认）

- **仓库**：新仓库与旧仓库共用一份库存，只扩大总容量；居民按最近的仓库取放点搬运。
- **集中火电**：动力管线简化为“12格内自动配对”，不需要单独铺管。
- **工艺废水**：收集作为设施附件（容器＋电线），产出比例为该配方用水的0.8。
- **其他复合塑料识别**：旧塑料再识别用“未识别的其他复合塑料计数”防止反复识别，每批固定60秒，没有按件6秒计。
- **填埋区**：固定为2×2。
- **投弃洞**：仍是主角的0.5秒交互，没有做10秒／10容量的岗位工序。
- **任务优先级**：没有做v1中1—5级的岗位优先级界面，沿用现有的固定任务顺序。
- **美术**：新物品没有专属图标；新设施复用最接近的已交付素材，按产线着色并加名牌。升降舱、结局CG和新设备状态图仍需美术制作。
