# 本地美术接入（2026-10-14）

本次将桌面 `喂——出来游戏素材` 中已生成的素材接入当前首区 Demo。生产配方、科技、价格、人口、地图大小、教程与存档规则沿用仓库现状。

## 接入结果

- 74 张 PNG 原文件复制到 `Assets/_Game/Art/Local`，SHA-256 记录在 `ImportManifest.json`；图片未重绘、改色或重新采样。
- 234 个 Unity Sprite：人物静态四向 24 个、交互姿势 72 个、图集 39 个、地面 64 个、其余单图 35 个。
- 男主用于当前主角；居民循环采用 4 种外观，移动时根据位移切换方向并轻微摇晃，暂停时停止摇晃。携带货物、主角交互和居民木工劳动使用已有姿势图。
- 女主的四向和交互姿势已经切片、登记在 `M1Appearance` 中。原 Demo 没有角色选择系统，本次没有添加该玩法。
- 已有木工台、装配工作台、拆解台、发电机、仓库、住房、社区路灯和洞使用对应的本地贴图；未建设的设施继续以半透明表示。
- 洞穴基岩、碎石、夯实地面分别用于外围、来料区、建设与通行区域；每张纹理划为 4×4 个切片，原图覆盖四格见方，减轻缩至一格时的细节拥挤。分区边界和压力提示仍保留。
- 木料、混合垃圾和废金属堆使用本地资源图；木料和混合垃圾超容量时显示较高堆体。真实种类、数量、预约信息仍由原模型与悬浮信息提供。
- 仓库 59 种现有物品均引用本地素材；新增头图用于菜单和页头。物品图标保持宽高比。

本地素材中的自动化机器、传送带、电线、勘探设备、矿机和返程载具已完成导入与切片，供后续功能引用。当前版本尚未实现这些设施的运行逻辑，它们不会因为导入图片而自动成为可建造设施。六种额外岩石、泥土仍只有待生成说明，不计入本次导入数量。

## 工程接入方式

1. 新素材与 `.meta` 一起保留；`M1Appearance.asset` 与 `Main.unity` 保存正式引用。
2. `LocalArtInstaller` 通过 Sprite Editor Data Provider 写入切片、脚底锚点与稳定子图引用，使用 Point、无 mipmap、无压缩设置。
3. `PrototypeProjectSetup.Setup` 在原设置完成后应用本地外观，避免构建或刷新场景把素材切回占位图。
4. `PrototypePresentationEditor` 在首次打开旧场景时安装本地外观；世界布局版本升级为 3、界面布局版本升级为 7，重建一次后可继续编辑保存的场景。
5. 建筑按世界尺寸等比缩放，地面适配单格，人物使用脚底锚点；界面方形控件与边界仍使用原有基础 UI 图形。

在项目根目录可执行：

```powershell
.\Tools\Unity.ps1 -Action Setup
.\Tools\Unity.ps1 -Action ValidateArt
.\Tools\Unity.ps1 -Action Test
.\Tools\Unity.ps1 -Action Build
.\Tools\Unity.ps1 -Action Smoke
```

如需重新从桌面复制原图，执行 `Tools/ImportLocalArt.py --source <素材目录>`，再运行 Setup；该工具依赖 Python、Pillow 和 NumPy，拒绝覆盖内容不同的同名图片。正常打开已接入的工程无需运行 Python。
