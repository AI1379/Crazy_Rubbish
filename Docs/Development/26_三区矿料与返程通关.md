# 第三区域、矿料与返程通关（2026-10-17）

本轮落实用户选择的完整通关主线。采用既定S6配方与数值，开放三区、地质勘探、持续开采、矿料加工、返程总成、总装试车、登舱及结局。没有固定整局小时数。

## 三区入口与科技

依次支付200钱开放二区、600钱开放三区。保留已建产线、居民、库存与地图地形。三区固定来料包含地质仪器、采掘设备、选矿设备、陶瓷窑、五件承重框架及集中火电旧件；运行中继续按三区类别预算落料。承重框架占三区旧件预算15%，其余旧件平分剩余预算。垃圾回收仍负责承力件、机电组件、工具、燃料等来源。

科技继续采用实际取得材料后免费即时解锁，扩区会重新检查已知材料与前置科技。单纯完成勘探只揭示矿点，矿石实际产出才触发对应加工科技。

## 勘探与采矿

勘探站每矿脉一次：人工30秒、机器90秒、负载2、扳手损耗1。完成后停止该次任务，选择下一矿脉即可继续。铁矿锚点(55,18)、铜矿(64,18)、陶土矿(69,8)，使用原数值配置坐标；区域页与世界标记可定位，右键矿点可进入建设预览。

持续采掘机只能建在已勘探锚点，3×3地基，初始朝向，每处一台。配方须与所在矿脉匹配。基础采掘每批4份，人工10秒加机器50秒、负载2；安装送料组件与控制模块后可用60秒机器阶段、负载2.5。矿脉暂定无限，输出容量、线路、人员、耐久与维护继续约束产率。维护恢复到既定重启值后恢复生产，不重置矿脉或制造额外矿石。

沿用已有分选、矿料炉和陶瓷配方。矿产钢/铜坯料与垃圾回收金属保持不同物品ID及共同市场规则；返程关键材料不能倾倒。三区小水源沿用原位置和预算，修正自然地块边界与水源归属编号不同造成的绑定问题；读档不补满水源。

## 唯一升降舱

旧检修平台固定地基(72,21)，4×4，初始朝向。返程装配场制作五类总成；各总成搬入检修平台后总装：结构架5、驱动2、制动2、控制1、卷缆1。总装人工120秒加机器180秒，机器负载4，人工需要2人及既定工具。

总装产物进入平台唯一载具槽，不进入普通输出、不切成货物、不要求工人搬运24容量整舱。再次总装被拒绝。带载测试人工30秒加机器150秒、负载12，更新同一载具的测试状态，不消耗或复制载具，也不会通关。

完成总装与测试均停在相应检查点，选择下一工序或确认登舱才继续。带舱平台不能移动、拆除或出售，避免丢失唯一载具；未总装的空平台仍按原规则处理。

## 登舱、运行与结局

试车通过后，主角走到平台操作侧，在设施菜单确认登舱并启动。暂停时可以确认，计时仍要恢复经营才开始。人工舱内准备10秒、机器爬升180有效秒、负载12；只需主角一名乘员，不再要求地面操作工陪同乘坐。地面维护继续负责检修与供电设备。

登舱后主角不能行走、拾取、搬货、参与其他岗位或取消载人批次。其他居民、工资、食水、垃圾输入、暴动与入侵计时继续。可以暂停经营或平台，缺电降速/停止，耐久耗尽等待维护；恢复条件后沿用在制进度。

路线为旧检修平台—隔离于垃圾落料通道的既有检修竖井—上层处理场出口。沿用本地升降舱贴图，世界中显示导轨与竖向爬升，故事高度480米不映射为额外经营地图。到达后才结算：从未实际倾倒为好结局；实际倾倒大于0且入侵前到达为普通结局；同一刻入侵与到达时入侵优先。死亡、暴动及入侵仍可导致失败。隐藏阈值和下层信息不提前公开。

结局使用既有像素素材与短文字画面，停止经营，提供新游戏或读取存档。结局不覆盖失败/返程前手动存档，新游戏回到最初。
