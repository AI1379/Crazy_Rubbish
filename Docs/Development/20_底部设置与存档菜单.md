# 底部设置与存档菜单（2026-10-16）

顶部的菜单、保存、读档入口合并到下栏右端的齿轮按钮。管理入口移至同一下栏，保持Tab快捷键；顶栏只显示区域、现金、经营时间与倍速。

点击齿轮展开向上的设置菜单，包含保存游戏、读取最近存档、主菜单、退出。沿用原有独立存档目录、最近存档读取、失败前手动存档保护和主菜单返回经营逻辑，不新增存档格式。

菜单默认收起，再次点击齿轮、点击关闭按钮、按Esc或点击外部均可收起。用于关闭菜单的外部点击不会同时下达地图点击操作。打开管理面板或右键菜单会收起设置，设置背景阻挡地图拖动和选择。

设置菜单本身不改变暂停状态，经营继续按原规则推进；仍可使用空格暂停。打开主菜单时按原规则停止经营，齿轮禁用，倍速控制隐藏；返回经营后恢复入口。

齿轮用界面网格绘制，沿用深色底和暖黄色选中配色。下栏入口与菜单按右下角定位，保持在屏幕范围内。

验证目标：构建Windows试玩，检查1280×800及1920×1080的布局、齿轮图标、菜单开合、鼠标阻挡、真实保存与恢复及主菜单往返，同时回归已有倍速、右键、框选、取水与零资金开局。核心经营数值不变；168项核心测试沿用上版通过的报告，不作为本轮重跑结果。本机使用Unity2022.3.22f1，正式工程目标仍为2022.3.62f3。

实测结果：Windows构建与场景验证通过；1280×800、1920×1080下的齿轮菜单开合、屏幕范围、鼠标阻挡、实际保存／恢复和主菜单往返均通过。倍速、右键菜单、框选指挥、河岸取水和零资金开局回归通过。两种分辨率均已检查实际截图。
