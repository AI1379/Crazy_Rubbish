# 界面与场景编辑

更新：2026-10-10。

## Scene空白的原因与修复

原Main场景只保存相机和原型脚本，地图、角色、地面物品和Canvas都在Start时创建。因此编辑状态看不到游戏场景。现在起步地图和完整UI保存为场景对象，脚本通过序列化引用更新它们；运行时只重建模拟拥有的地面物品和居民，不重复生成地图或Canvas。

Hierarchy中展开Crazy Rubbish：World包含网格、分区边界、设施、主角和Ground Items；Interface包含Header、Management和Woodwork。初始物品在Scene中可见，编辑状态不推进时间、工资或自动存档。

打开Assets/_Game/Scenes/Main.unity，使用Crazy Rubbish → Focus World in Scene聚焦地图。选中Interface后按F可查看UI布局。首次载入旧场景会自动生成缺失的对象；场景原本有未保存修改时，只标记修改，不自动保存。

Crazy Rubbish → Refresh Scene Presentation会按代码重新生成World和Interface，支持Undo；手工调整过布局后，只在需要恢复默认布局时使用。保存场景后，按钮在运行时重新绑定游戏动作。

设施交互、建设占格和寻路坐标仍由Core的模拟规则决定；移动设施图像不会同步修改这些逻辑坐标。地面物品与角色的位置、状态颜色由模拟更新。

## 界面与地图

- 保留深色工坊风格，使用暖金色标记操作、绿色标记建设区，统一标题、间距、按钮边界与状态条。
- 右侧固定显示电力、居民、配送与工资概况，下方分为现场、人员、仓库三页，各页独立滚动。
- 现场页将建设、投料搬运、拆解批次、采购交易分组；人员页提供招募、岗位、发薪与居民活动/钱包。
- 仓库页默认只显示背包或仓库持有的物品，提供空状态引导；全部物品按钮切换完整目录，保留拾取、取出、放下、出售操作。
- 当前配方和游戏速度有选中状态。地图用边界区分来料区、建设区和设施占格；滚轮以鼠标位置为中心缩放，中键拖动地图。
- 地图视口与UI采用相同的1600宽度参考布局，根据窗口尺寸重算，支持1280×800和1920×1080等桌面窗口。

## 验证

PrototypePresentationEditor.ValidateSavedPresentation会保存并重新打开Main，检查编辑状态下的地图、初始物品、UI引用和唯一Canvas，并确认没有启动模拟。结果写入TestResults/presentation.json。

独立运行的Smoke除了原有经营、工资、暂停和重开，还验证保存后的按钮绑定、三页切换、全部物品目录，以及重开后的地面物品数量。截图生成使用当前窗口尺寸，并额外保存人员和仓库页。

2026-10-10验证：保存重开后包含1059个SpriteRenderer和280个按钮，编辑状态未启动模拟；45项EditMode测试通过，Windows开发构建通过。1280×800和1920×1080独立运行均通过按钮/页签、存档恢复和重开检查，完成12批木工、1批拆解、35趟配送与5人首期50钱工资，现金34.92。已查看两种尺寸的初始画面、人员/仓库页及流程完成画面；截图位于Artifacts/Presentation-preview*.png。
