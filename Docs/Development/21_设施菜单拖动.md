# 设施菜单拖动（2026-10-16）

框选后的“框内设施”列表和单个设施右键菜单均可按住顶部标题栏，用鼠标左键拖动。标题区增加底色与三条短线作为拖动提示；关闭按钮独立于拖动区。

共用同一弹出菜单框架的人物、物品、洞口与水面菜单同步支持标题拖动。正文仍用于滚动和点击操作，不会把正文滚动变成窗口移动。拖动不影响镜头、框选、人物移动或生产状态。

窗口四边保留画布8单位边距，按画布缩放换算鼠标位移；拖到边缘时限制在屏幕内。窗口不保存到游戏存档，每次重新右键或框选仍在鼠标附近打开。从已移动列表进入设施详情或切换选择类别时，沿用当前菜单位置，并根据新内容高度重新限制边界。

Esc、关闭按钮、原有菜单动作及鼠标阻挡继续有效。下栏设置、顶栏倍速和默认收起的管理栏保持当前规则。

验证目标：1280×800与1920×1080中检查真实事件命中、标题移动距离、四边限制、内容滚动路由、镜头不跟随、菜单位置继承，以及移动后的设施开停和关闭。回归原有存读档、框选、取水及零资金开局。核心经营数值不变，168项核心测试报告为上版通过基线。本机使用Unity2022.3.22f1，正式工程目标仍为2022.3.62f3。

实测结果：Windows构建成功；1280×800与1920×1080的菜单标题事件命中、位移缩放、四边限制、内容滚动路由、镜头隔离、详情位置继承、移动后设施开停、关闭按钮及Esc检查均通过。原有存读档、倍速、框选、取水和零资金开局回归通过；本轮没有重跑结构未改动的场景验证与核心测试，随包保留上一版报告作为基线。
