# 嵌入式时间控制条（2026-10-16）

本轮将顶栏的大号暂停、1×、2×、3×按钮改为贴合顶栏右端的紧凑控制条，参考环世界的时间控制排列，使用本项目现有深色与暖黄色配色。

- 上行显示经营时间及当前状态，下行依次为暂停、一档、二档、三档图标，附空格和数字键提示。
- 当前状态以暖黄色高亮。暂停时只高亮暂停；运行时只高亮当前速度。
- 点击暂停或按空格切换暂停／继续，继续时沿用暂停前的速度。
- 点击速度档或按数字键1／2／3，直接以对应倍率运行，包括从暂停恢复。
- 控制条随顶栏右边缘定位，不覆盖地图；背景阻挡地图鼠标操作。主菜单中隐藏并禁用时间操作。
- 菜单、保存、读档、管理入口保留；右侧管理栏仍默认收起。

本轮不调整模拟倍率：一、二、三档仍分别为真实时间的1、2、3倍。图标由界面网格绘制，无需额外贴图。

验证目标：Windows构建，1280×800与1920×1080下检查控件贴边、屏幕范围、管理按钮间距、鼠标阻挡、暂停／恢复、高亮和实际倍率；同时回归原有右键菜单、框选指挥、取水与开局流程。具体结果见随包检查报告。本机使用Unity2022.3.22f1，正式工程目标仍为2022.3.62f3。

实测结果：最终Windows构建成功；1280×800与1920×1080的时间控制、状态同步、原有菜单／框选／取水及零资金开局回归均通过。场景验证通过。本次没有改动核心经营规则，随包168项核心测试报告作为上一版已通过的基线保留，未声称本轮重新运行。
