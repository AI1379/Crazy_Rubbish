# 设计总览

更新：2026-10-08。现行基线为[S4项目维护版](00_合并策划案.md)，S1—S3和旧17天范围保留为历史。用户本轮授权按新版更新工程；数字仍为首版方案，需试玩。

## 主题与流程

Unity 2022.3.62f3、2D俯视垃圾回收与基建经营。上层工人坠入中层，组织居民发展生产并尝试返回上层。垃圾提供资源，也占地降低附近人工效率；改善产线、永久填埋与向洞倾倒形成取舍。

拾取→手工加工→建设发电→认可招募→岗位、运输、供给和发薪→半自动及自动生产→扩区与勘探→返程或失败。整局正常速度3—4小时为目标，尚未验证。

## 全局规则

- 开局0钱、住房6人、仓库80，固定拾取物保障；首批最多5人免招募费，工资不免。
- 对应材料首次取得自动解锁，不收费、不消费、不花研究时间；建设另扣完整材料。
- 建设瞬间完成，暂停蓝图恢复后完成；移拆内部物品先入仓库，溢出留旧址。
- 工具只加速适用人工；机器需维护，简陋发电机只补燃料。工业及农业不能侵占饮水保护。
- 消费与生产共用库存，现金双方真实转移。仓库和设备内物品不计地面压力，仅发电灰渣豁免。
- 满地垃圾实际堆高，不用隐藏队列。统一游戏时间受暂停倍速影响；存档保留经济及结局状态。

当前完成度见[实施顺序](../Development/01_实施顺序与验收.md)，未实现内容不能视为已经完成。返程载具类型、路线和失败后旧存档仍待定。
