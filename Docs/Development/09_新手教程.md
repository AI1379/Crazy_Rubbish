# 新手教程

更新：2026-10-12，首区 Demo 0.3.0-demo.2。

## 游戏内入口

新游戏默认进入右侧“教程”页。先阅读欢迎说明，点“开始教程”；准备页会冻结游戏时间，避免尚未学会操作就缺供。开始后按实际游戏时间推进，空格仍可暂停，1/2/3为倍速。

“跳过 / 收起”可直接进入自由经营；教程页保留“继续教程”和上一课/下一课，随时重新查看。不重开游戏、不增删资源、不改变现金。翻阅课程本身不暂停时间，必要时先按空格。

## 课程

| 步骤 | 学习内容 | 实际完成条件 |
|---|---|---|
| 1 | 走近、选择并拾取手锯 | 实际取得可用手锯 |
| 2 | 生活保障、容量与仓库取用点 | 食物12、饮水24已入库；已正常运行的旧局可认可既有供给 |
| 3 | 分趟搬起步建材 | 木料16、紧固件4入库；已建木工的旧局认可既有建设 |
| 4 | 建木工地点、暂停蓝图 | 木工实际建成 |
| 5 | 取原料、现场投料、作业、搬成品 | 两批木板已实际生产并入库，不凭生产次数跳过运输 |
| 6 | 保留建材、建设工作台和拆解地点 | 两个地点实际建成 |
| 7 | 带螺丝刀和旧设备、拆解及搬运 | 一批旧设备已拆，输出和背包中拆解物已搬完 |
| 8 | 发电组件、建设和补燃料 | 发电机实际发出电力 |
| 9 | 招募、手锯交接、指定木工 | 5名居民、地点有手锯、实际指定木工 |
| 10 | 出售仓库商品、等待账单、发薪 | 首期50钱工资付清，无欠薪 |
| 11 | 木柄、工具工作端、工作台作业 | 实际制作一把替补工具 |
| 12 | 工资/饮水保护与融资取舍 | demo阶段目标达成：现金200，无欠薪/缺供 |

完成后可以继续经营或收起教程。各阶段认可已完成的游戏事实，因此旧局继续教程无需重新建设、重新发薪或重新制作。翻阅先前课程不会倒退实际教程进度。

## 提示与操作

- 每步展示课程说明、当前建议动作和地图坐标。地图用金色方框标出目标，定位时适当放大视角；滚轮仍可缩放。
- 建议操作按钮先带主角走到目标；到达后再次点击才做实际拾取、入库、投料或作业。所有动作调用原有游戏规则，照常消耗时间、材料和现金。
- “显示对应按钮”切换到普通操作所在页，滚动至按钮并加金色边框。仓库物品选择会打开全部目录，方便指定拾取种类。
- 背包满会建议先入库；成品未搬走会提示取出；人工岗位在实际生产时提示站着等待，不反复开停岗位。暂停施工会提示先恢复运行。
- 教程仍允许自由使用键盘、普通按钮和其他页，不限制经营。缺供、欠薪与失败仍使用真实游戏规则。
- 融资步骤只定位交易选项，不自动出售技术。玩家需选择融资方式；技术确认窗口继续显示永久售价损失，也可不卖技术而继续生产或拆解。
