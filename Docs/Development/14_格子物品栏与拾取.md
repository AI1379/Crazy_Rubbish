# 格子物品栏与地面拾取

更新：2026-10-14。按用户确认采用类似MC的整叠拿放、右键拆分、拖拽和Shift快速转移；保留背包8、仓库80的原有体积容量规则。

## 地面拾取

原来一个地面图标可能代表多份甚至多类物品，E默认只拿一份，数量又隐藏，容易让人误以为物品没有消失。现在普通E尽量拿走所选堆中背包能装下的全部物品；拿不完时保留真实余量，操作反馈说明剩余数量。拿空后立即禁用并销毁对应显示对象，不留一帧可点击的旧图标。

附近的堆显示数量。自然来料有空位时优先将不同种类分开，同种仍可合堆；来料区挤满时仍允许混堆和后续溢出，不删除实物。混堆的默认拾取优先级与可见图标一致。物品栏中的附近地面格按具体堆ID拾取，避免拿到另一堆同名物品。

## 格子物品栏

- I或底部“背包”入口打开物品栏。远离仓库时，上方显示附近地面物品、下方显示背包；靠近仓库时，上方显示仓库、下方显示背包。
- 点击场景仓库会先走到门前，再自动打开。教程可预览远处仓库，但需要到场才能实际存取。
- 左键拿起整叠，再点目标格放下或交换；右键拿起向上取整的一半，拿着物品时右键放一份；也支持拖动到目标格。
- Shift点击在仓库与背包之间快速转移，容量不够时只移能装下的部分，剩余留在原容器。附近地面左键取整堆，右键取一份。
- 同类物品每格最多64份。格子用于显示与整理，空格不代表还有体积容量；窗口分别显示背包与仓库实际占用。仓库物品较多时可翻页。
- 指向格子显示名称、用途、单份容量和预约数量。已预约或正在使用的工具不能被取走。鼠标拿起工具期间也会锁住对应实例，避免它同时被生产使用。
- 容器内部整理立即生效；背包与仓库之间的实物搬运沿用0.5秒交互。库存不提前改变，窗口内显示搬运结果与容量不足等反馈。
- 物品栏打开时经营继续，主角的行走和E/Q/F快捷动作暂停接收；空格仍可暂停游戏。I、Esc或关闭按钮会将手中物品退回；尚未完成的格子间搬运取消，不自动丢到地上。
- 持有鼠标物品期间推迟自动存档；手动保存要求先放下或关闭。实际格子排列与拆分随存档恢复；旧档首次打开时按现有库存生成格子。
- 旧的逐项列表作为“物品图鉴”保留，用于完整目录及按品类操作。日常存取改走格子窗口。Q整批入库仍保留，并继续保留随身手锯；格子界面可明确选择将手锯存入仓库。

## 回归修复

新的落地分布改变了运输时序，完整教程验收暴露出木板切木柄时的旧卡点：输入容量缩小但仍有多余木料或在途配送。现在切换等待旧配送落地、停止继续补旧配方输入；教程提示取回多余木料再入库，并优先处理到期工资，避免一直等待。
