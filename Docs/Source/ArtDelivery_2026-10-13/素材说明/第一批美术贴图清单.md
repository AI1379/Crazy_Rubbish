### 25.1 这批素材服务什么玩法

成员2负责美术，两名程序分别接入自己负责的功能。本批素材要支撑第24章的完整操作片段：移动、拾取、手工木料加工、建设发电机、补燃料与接线、招募、安排生产和运输、入仓、销售、首次发薪。全游戏仍有三个可游玩区域，本批只是第一次集成交付。

本文把“贴图”分为场景精灵、人物单张贴图、物品图标、状态覆盖层及界面切图。美工交付可用资源和标注，两名程序负责数量、进度、光照、按钮、动画与游戏状态的连接。

已确定：整体简洁像素风，视觉参考《异星工厂》；2D俯视、网格建设；主角和居民都是人类；男女主与居民各四向静态贴图，使用程序摇晃效果模拟行走；垃圾和产线争夺空间；洞开局可见且不解释去向。人物外貌、色板、建筑装饰和具体像素尺寸仍通过样张统一。下述尺寸与建筑效果属于建议规格。

视觉方向：参考《异星工厂》的工厂组织方式，让建筑、传送带、物料和通行空间共同呈现产线。参考图可查看[《异星工厂》官方截图](https://factorio.com/game/screenshots)。本项目的具体作画方案如下，属于执行建议：

- 建筑：使用清晰的大轮廓，保留与功能有关的少量结构，例如木工台的木料与锯切区、发电机的炉口与输出部件。以2—3档明暗表现体积，细节在默认缩放下仍可辨认。
- 物流：电线、后续传送带、接口和运送中的物品视觉分开，走向与进出口明确；排列后能看清物料从哪里来、到哪里去。
- 地面与垃圾：地面纹理克制，垃圾用几种有代表性的形状和可增减模块表现；堆高突出空间压力，同时保留人物及建筑轮廓。
- 配色：建议土灰、灰褐作为环境底色，木材、金属、水与通电状态用不同颜色和形状区分。具体色板先通过样张统一。
- 人物：男女主与居民均采用四向静态贴图，程序摇晃模拟行走；轮廓清晰，与背景有足够对比。
- 界面：面板、边框和图标采用同一像素风，以库存、产率、供电、岗位和工资信息为中心；文本由界面动态显示。

### 25.2 通用交付规格

| 项目 | 建议规格 | 交付时注意什么 |
|---|---|---|
| 视角 | 与实际网格一致的俯视；可以看见少量立面 | 所有设施采用同一角度；避免建筑呈斜菱形而实际占地是正方形 |
| 地面比例 | 先用64像素代表1格 | 2×2地面范围对应128×128像素，3×3对应192×192；团队样张确定后统一调整 |
| 角色画布 | 建议逻辑画布64×96像素，男女主与居民各每向1张，人物脚下宽度小于1格 | 标脚底锚点；按移动方向切换静态图，摇晃由程序实现，不交逐帧行走动画 |
| 图标 | 64×64透明底，检查缩到32×32仍能认出 | 轮廓优先，数量和耐久文字由界面显示 |
| 文件格式 | PNG切图＋可编辑源文件 | 角色、建筑、物品透明底；地面底纹可不透明；不只交合并后的展示图 |
| 锚点 | 角色标脚底；建筑标占地原点与交互侧 | 示例图画出网格、占地、站位；有透明边时写明偏移，程序据此配置 |
| 图层 | 地面、主体、阴影、运行效果、状态标记分开 | 不把垃圾数量、文字、选中框、产权线和灯光全部烘焙进底图 |
| 建筑方向 | 首批木料地点、发电机按旋转功能准备4向静态表现 | 可以程序旋转单图，但必须实测清晰；不适合旋转的立面由美工补方向图 |
| 状态一致性 | 建筑不同状态使用相同画布和锚点，人物摇晃以脚底为基准 | 状态切换不改变占格；人物视觉摇晃不改变实际网格位置和寻路 |
| 配色 | 地面和垃圾背景较克制，交互物、人物、状态有清晰对比 | 主角和居民可用不同衣物配色；状态同时用形状或符号识别 |
| 命名 | 类型_对象；建筑有方向或状态时再加后缀 | 如 chr_worker.png、chr_hero_up.png、bld_wood_south_idle.png；使用统一物品ID与名称对照表 |

建筑主体可以超过地面占格的画布，例如灯杆和屋顶，但要在交付说明中标出实际占地。门口、操作侧、洞的边缘必须与交互规则对应。建筑方向稿只改变视觉方向，不自行改变配方、岗位或数值。

首先交主角、居民和木料地点各一张样图，在同一格子上验证比例后再批量绘制。整体采用简洁像素风，统一像素密度和清晰边缘；人物按单张静态贴图交付。

男主与女主为同等地位的可选主角，开局二选一。两位主角分别上、下、左、右四向静态像素贴图，每向1张；居民也采用上、下、左、右四向静态图。行走继续使用程序摇晃，不制作逐帧行走或劳动动画。两种选择共用主角能力、生产效率、科技知识、开局资源、剧情任务与结局判定；存档记录选择，读档恢复相应外观。

|---|---|---|
| 男主 | 四向静态贴图各1张，蓝灰工作服、棕色背带裤、帽子、手套和靴子 | 成员1按开局选择加载角色、按移动方向切换贴图，移动时轻微摇晃，停下后恢复静止 |

| 居民 | 4套造型，每套四向静态贴图各1张；灰绿上衣男居民、红棕上衣女居民、灰蓝外套男居民、浅褐上衣年长女居民，均为本版生成外观 | 成员3按移动方向切换静态图，沿用摇晃表现，不因岗位补角色动画 |

| 拾取表现 | 6个角色各四向完整俯身拾取姿势，共24个 | 实际拾取时切姿势，完成后返回对应状态；不改变物品领取时机 |
| 手工锯切 | 6个角色各四向完整锯切木料姿势，共24个 | 只用于手工锯切工序；身体、手锯与木料在同一静态姿势内，不另叠加相同工具层 |

当前男主4张、女主4张、居民4套共16张，合计24张人物静态图。居民无需逐人重画，可复用这些造型；外观不改变工资、效率、科技、岗位或其他能力。男女主及居民四向PNG均已生成并分别打包；首套居民为chr_worker_up/down/left/right.png，新增3套为chr_worker_02/03/04_方向.png，完整4套见《NPC造型合集.zip》；男主文件名为chr_hero_up/down/left/right.png，女主为chr_hero_female_up/down/left/right.png；美工与程序导入时核对比例和脚底对齐。美工标出各姿势的支撑脚锚点，程序统一显示比例、摇晃幅度和频率。生成图为1024×1536像素，尚未导出为64×96原生低分辨率素材，也未在Unity内验证。

建议摇晃围绕脚底进行小幅往返，人物逻辑位置仍按正常移动计算，选中圈和交互站位跟随逻辑位置。速度变化时表现应协调，停止、等待和游戏暂停时停止行走摇晃。具体幅度与频率在实际缩放下调试，避免模糊像素边缘或明显抖动。

交互姿势新增6张1024×1536透明图集，每张12个完整姿势，共72个；每动作每方向只有1帧，不是逐帧动画。每张从上往下为搬运、拾取、锯切，通常从左往右为上、下、左、右；worker_03的锯切一行实际为上、下、右、左，以随包切片表为准。实际留白和姿势边界不等宽等高，不直接按256×512切片；附72条建议矩形，需要在Unity校准透明边缘、显示大小和脚底。原始图未经裁切或缩放，尚未输出72张拆分PNG。

动作显示由实际任务驱动：正在拾取时使用拾取姿势，正在手工锯切时使用锯切姿势，有货移动时使用搬运姿势，其他状态使用原站立图。取消、完成、缺工具或等待时同步恢复对应状态；锯切姿势不用于所有制造工序。图中箱子与工具不作为额外库存，也不改变工资、效率、耐久或加工进度。站位、选中圈与碰撞沿用逻辑脚底坐标，切换姿势不让角色跳位。

站在木料操作侧时仍能辨认主角与居民。独立头像、招募过场及暴动剧情素材按后续系统另行排期，不恢复原逐帧人物动画要求。

木料地点的工作覆盖层只在实际加工时出现，等待原料或手动停止时不播放锯切。发电机缺燃料时不能持续冒烟或发光；接线断开时下游路灯应灭。住房亮灯是供电反馈，不在本批额外增加家具或住户外出流程。

发电机、仓库和路灯中的物资数、容量、输出等由程序显示。美工画的是清晰的主体和状态层，不需要画完整现实机械图纸。运行效果可先用2帧，预算不足时用静态覆盖层也可验收；不要求浓烟粒子、复杂机械动画。

电线另外交：直线、转角、端点3种单格素材；横竖由旋转复用。若首批电网实现分支，再补T形与十字2种连接。线在地面上易辨认且不能挡住角色；通电表现由程序染色或叠加亮线。电线不是后续传送带，不画输送物品的动画。

### 25.6 首批12种必做图标

| 物品 | 推荐轮廓 | 容易混淆的地方与要求 |
|---|---|---|
| 废木料 | 长短不一、边缘破损的旧木段 | 和整齐木板区分；垃圾山、库存、燃料栏共用辨识特征 |
| 木板 | 2—3块平直规整木板 | 表示加工成果；不能只给废木料换一个颜色 |
| 木料碎屑 | 细小木屑组成的小堆 | 和整段木料明显不同，同时用于燃料显示 |
| 回收紧固件 | 螺栓、螺母等少量部件组合 | 小尺寸仍有“连接件”的轮廓，不画成普通钢块 |
| 钢铁零件 | 带孔金属片或简单机械零件组合 | 和原始金属垃圾、紧固件区分；不是钢锭 |
| 回收电线 | 一捆线圈带露出的端头 | 和场景中铺好的线材统一材质，图标使用卷线轮廓 |
| 回收热动力组件 | 带管路或驱动结构的小型模块 | 与发电组件用结构区分；这是发电机建材，不是另一台完整发电机 |
| 发电组件 | 带电连接端与转轴结构的小型模块 | 与热动力组件的机械轮廓不同；不用闪电代替整个零件 |
| 手锯 | 清晰锯片和握柄 | 能看出是可用工具；以后损坏工具使用同图＋破损标记 |
| 未开封食物 | 密封包装或罐装食品 | 不画成腐败食物；不指定尚未决定的品牌、菜品或食谱 |
| 饮用水 | 密封水瓶或水容器＋水滴特征 | 和工艺容器区分；升数由界面显示 |
| 金钱 | 通用货币符号或叠放币片 | 作为经济界面符号，不自行设定世界货币名称；玩家现金与居民钱包都可复用 |

12种指逻辑图标种类，不含角色、建筑或状态层。图标放在同一风格的槽位中；数量、价值、耐久和耗时都用动态文字，避免修改数值时重画贴图。

初始垃圾中还有9类物品，首次集成后优先补齐：铜零件、肥皂、废纺织物、旧衣服、锤、螺丝刀、扳手、剪刀、针线工具。铜零件采用导电金属部件轮廓；肥皂是皂块；废纺织物是零碎布料，旧衣服有完整衣服外形；五类工具以真实轮廓区分。首批尚未完成图标时可以共用临时图标，并显示真实名称；不删掉对应物品。

### 25.7 界面切图与状态提示

| 交付内容 | 需要画什么 | 在哪些界面使用 |
|---|---|---|
| 通用面板 | 可拉伸的面板背景、边框、标题区，标出可拉伸区域 | 仓库、建造、建筑信息、人员、工资 |
| 按钮 | 普通、悬停、按下、不可用的样式 | 程序可用同一底图染色实现状态，美工给出效果示例 |
| 物品槽与选中框 | 空槽、选中边框、容量条底／填充、进度条底／填充 | 图标与文字独立放置，物品数量不能画死 |
| 工作状态图标 | 等原料、缺工具、输出满、无路可达、手动暂停、缺燃料、缺电，共7类 | 建筑旁或选中界面；选中时附具体原因文字 |
| 交互提示 | 1套通用提示框和箭头／高亮样式 | 拾取、加工、建设、接线、招募、指定岗位等 |
| 工资提示 | 到期提醒样式、应付与实付栏目、确认按钮 | 首次发薪；不提前揭露死亡结局 |
| 时间控制 | 暂停／继续符号和按钮风格 | 倍速数字、游戏时间与发薪剩余时间用动态文字 |
| 主菜单 | 标题位置、开始新游戏、男女主选择与返回／退出按钮样式 | 角色选择复用两位主角正面图和同一选中框，显示两者能力一致；背景可复用场景截图 |

七类工作状态用图形区分，例如空箱、工具感叹号、满箱、断开的脚印、暂停符号、熄灭火焰、断电符号。颜色只是辅助，不能全部使用同一个红点。居民吃喝可以直接复用食物和水图标。

界面布局需要4张标注稿：①仓库与销售；②建造与建筑详情；③居民名单、指定岗位与工作状态；④工资。每张写清数量、容量、进度、等待原因、人员姓名／岗位、个人钱包、应付工资／实付工资的位置；不要求把所有面板挤进同一屏。

七步教学共用同一提示框样式，以动态文字说明“拾取→木工→发电→招募→指派→售卖→发薪”。给出指向按钮和物品的高亮示例即可，不必画七幅独立插画。接线到住房／路灯为供电演示，不新增认可门槛。

提交前与两名程序完成以下检查：

1. 在实际游戏默认缩放下能认出主角、居民、废木料、木板、碎屑；不能只在绘画软件放大看。
