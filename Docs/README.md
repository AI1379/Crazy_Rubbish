## 整理规则

1. S1 自己明确说明第三、十二、十三节为此前基线，首批资源与产线以第十六节及 S2 的后续细化理解；新增纺织品与生活用品不能被旧“两条短产线”上限截断。
2. 明确重复的内容合并，功能称呼及别名归并；这些名称不决定最终显示名，也不决定库存状态是否独立成物品。
3. 未确认的材料数量、产出、时长、人口、价格、掉落表、残余物及通关条件继续保持待定。
4. 同日期资料没有可验证的先后顺序；出现实质差异时保留两边表述，列入差异清单，不默默判断哪份有效。
5. 策划原文中的建议、禁则与历史确认是资料内容；建设和上传范围来自用户请求。初始化曾通过 UVCS 上传；2026 年 10 月 7 日按用户要求改用公开 GitHub 仓库，并暂时保留 Plastic 工作区。

后续确认配方时，应更新确认来源和整理版，再同步实现。M1 先采用明确标注的实验配置验证木工流程，详见原型说明；原始待定项不因此自动定案。
