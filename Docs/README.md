1. 本轮用户要求按新版更新文档并推进工程，S4覆盖旧版制作范围；不将工资、暴动、维护等继续标为延期。
2. Source是输入快照，不改写。维护版只同步已确定Unity版本、修正编号；规则与首版数字沿用S4。
3. 来源标为用户确认、首版方案、待定的状态保留；尚未在Unity验证的数值不能宣称已验证。
4. 工程临时选择和分阶段缺口写在开发说明，不伪装成完整实现，不擅补返回路线等明确待定设计。
5. 后续修改以主文档为基线，再更新索引、受影响的分项和实现。历史17天不是当前工期承诺。
