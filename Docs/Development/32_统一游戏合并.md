# 统一游戏合并（2026-10-19）

## 已确认的方向

用户要求以release为底座，将main独有功能整理到同一套游戏；地图采用release，遇到规则冲突采用release。取消上一轮双入口候选的玩家入口。历史Prototype留作回归，不承载正常玩家会话。

## 沿用release的规则

- 250×250自然洞室、河网、水塘、三区土地、矿脉和返程位置；未移入main的矩形地图或产权边界。
- S6食水v1.1及201物品、53设施、216配方、54科技。固定来料仍在区域开放时生成，没有加入main的渐进发料或12步Demo结算。
- E保持单份拾取，Q保持按release规则入库/投料；鼠标操作、框选指挥、人员待命与恢复工作沿用release。
- 独立仓库、真实运输、食水与种薯保留、手动发薪和既有采购预算不变。
- 生产阶段扣料、取消返回、取水来源品质、蒸汽管网、锅炉供水、倾倒工序及载人返程不可取消均沿用release。没有引入main中有冲突的退料、锅炉或返程撤回规则。

## 整理进入同一游戏的main功能

### 格子背包与精确存取

I或底栏背包按钮打开窗口。上栏显示当前近处仓库；无近处仓库时显示附近地面。背包27格/页、仓库54格/页，每格最多64份为显示整理上限，实际总容量仍由物品体积决定，库存较多时自动增加页数。

- 左键整叠拿放、同类合并、不同物品交换；右键拆半/放一份；拖拽与Shift快速转移。
- 只操作选中的这一座仓库。跨容器操作仍需在release允许的操作距离内；容量不足时保留原物品，快速转移只移动实际放得下的数量。
- 水等小数数量保留到release的万分之一计量；工具、完整耗材和压缩包实例不拆成碎片。
- 来源、品质、工具耐久、未完成批次状态和压缩包内容均单独保留，不通过同名图标混合。
- 手持物品仍留在真实来源中并预约，工人和生产不能再次使用。关闭窗口放回，保存与自动保存等待放下，避免把临时鼠标预约写进存档。
- 地面格子绑定实际堆和批次，拾取继续使用release距离与耗时；部分预约或已消失物品不会重定向到另一批同名物品。
- 物品栏开启时经营继续，屏蔽地图和人物快捷动作，空格与倍速仍可使用。窗口自身阻挡地图点击。

### 经营与界面便利

- 保留release原库存列表作为物品图鉴，格子窗口提供物品与品质信息、全仓可售数量和预计收入，以及1份/5份采购与出售数量选择。
- 出售预估按release的市场压力、品质耐久、生活保留与零钱余数计算，查看不会修改台账。
- 建设目录可查看缺料和采购费用，确认后一次采购缺少的可购物资。按release价格、现金和真实仓容预检；条件不足时整笔拒绝，不扣钱、不补资源、不自动建造。
- 初次实际取得物品时显示用途提示，不增加科技费用、教学门槛或强制暂停。
- 设置加入自适应、紧凑、大号界面，随尺寸调整管理栏和地图可视区；验收模式不写玩家个人偏好。

## 数据与历史存档

仍使用S6的schema1、配置版本与S6PlanSaves目录；仅增加可选的格子布局字段和精确拾取标识。读取没有这些字段的旧S6存档时按真实库存重建布局，不补发物资。main模式2—6的旧存档保留在原目录，没有自动转换到另一地图与食水规则。历史对象在编辑器内保持关闭并标记EditorOnly，构建时连同其场景引用一起剥离；正式玩家包不含历史Prototype场景对象。历史规则通过EditMode回归，正常菜单与-legacyGame入口均已取消。Smoke与SmokePlan均验收统一游戏。

## 验证

全部使用工程要求的Unity 2022.3.62f3：

- 完整EditMode：374/374通过，包含18项新增物品栏、品质/实例、预约、交换、保存和采购回归，以及两条分支既有全部测试。
- 场景、原main美术、release美术验证通过。资产GUID与meta检查通过。
- PowerShell及打包检查26项通过，actionlint工作流检查通过。发布工作流新增统一物品栏与存档验收。
- Windows非Development构建`0.1.0-merge.2`通过。正式Player中包含所有关闭对象的搜索也找不到历史PrototypeGame对象，确认EditorOnly剥离生效。
- 1280×800、1920×1080与无图形模式下，统一物品栏验收全部通过：实际指针命中、右键拆分/放一份、拖动、Shift转移、交换、容量与生活保留、来源品质和工具耐久、建设缺料采购、三种界面大小以及实际磁盘存读档。已查看对应截图。
- 既有S6主线在无图形、1280×800与1920×1080通过：零资金真实开局、生产、独立运输、传送带、三区、返程结局、教程、建设搜索、设置及存读档。

结构化结果位于`Artifacts/UnifiedGame/verification-summary.json`和`source-audit.json`，完整规则报告为`TestResults/unified-full-editmode.xml`。玩家包另经打包完整性与校验值检查。
