# 右上教程与选中人物动画（2026-10-17）

新手教程集成到右上角倍速控制条下方。默认显示当前步骤、查看目标和完整教程入口；可收起成一行，随时展开。完整说明在同一位置展开为可滚动面板，包含操作速查、前期步骤及寻找物资入口。完成已有教学条件后自动更新当前步骤；扩区和生产仍不受教程完成度限制。

“查看当前目标”按步骤定位缺少的开局物资、已有木工地点或发电机，或打开建设、居民及区域管理。定位本身不移动主角、不自动暂停、不推进时间。完整教程原有明确的“寻找”“前往”按钮仍执行其移动操作。管理面板展开时暂时隐藏教程，关闭管理后恢复；原管理内教程入口转到右上角。主菜单和存档窗口隐藏教程。Esc优先收起展开的完整说明；普通刷新保留滚动位置。

人物行走原先只比较相邻画面刷新的位置差，重复刷新或模拟移动更新之间的空隙会立即把倾斜归零。现保留最近移动状态至少0.15游戏秒（或1.5个模拟步长，取较大者），以游戏时间计算摇晃；选择人物、打开人物菜单和刷新信息不再清除行走姿势。暂停或停止移动后归零；不改变寻路、移动速度、岗位和运输规则。人物保持可见，登舱主角继续按返程规则隐藏。

运行回归覆盖：右上角定位与屏幕边界、点击不穿透、收起重开、完整教程滚动与实时步骤、定位不移动人物、管理和主菜单切换，以及主角和居民被选中移动时重复刷新仍保持摇晃、暂停和到达后停止摇晃。双分辨率截图和最终结果见交付检查。

验证结果：219项规则回归全部通过；最终Windows构建、场景核验和1280×800、1920×1080两种分辨率运行回归均通过。已人工检查两种尺寸的教程截图。既有自动化、食水与工资提示、存档和三区返程回归继续通过。目标Unity版本保持2022.3.62f3，本机验证使用2022.3.22f1。
