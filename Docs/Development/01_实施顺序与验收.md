# 实施顺序与验收

本文件为根据当前资料整理的后续开发建议；不是新增玩法确认，也不重新承诺原 17 天工期。

## 初始化基线（cs:1）

- Unity 2022.3.62f3，内置渲染管线，默认 2D 编辑环境。
- 空白 Main 场景，只有正交摄像机；不包含主角、地图或玩法代码。
- 2D Sprite、Tilemap Editor、Input System、uGUI、TextMesh Pro、Test Framework、Visual Studio Editor、Unity Version Control，固定依赖与锁文件。
- Art、Audio、Data、Prefabs、Scenes、Scripts、UI、Editor、Tests 目录占位。
- 原文归档、整理文档、文档差异和待确认清单。
- 沿用已有 UVCS 云仓库、忽略缓存、文本规范和初始 Checkin。

初始化时验证 Unity 能成功导入并解析依赖，Main 场景引用正确，`.meta` 齐全，原文副本一致，UVCS 提交中没有缓存或玩法代码。当时没有开始玩法测试；当前 M1 的实现和验证另见原型说明。

## 建议里程碑

M1 的首个木工流程已有初步实现，操作、实验参数和验证方法见 [M1 原型说明](03_M1原型说明.md)。初始空白骨架的说明保留为基线记录；后续范围仍按下表推进。

| 顺序 | 目标 | 后续验收 |
|---|---|---|
| M1 | 确认首个纵向流程与开局供给后，实现拾取、木工、有限仓库、出售与初步堆积压力 | 无需改开发状态，能把指定垃圾加工为可用产物；空间不足和缺工具能提示并恢复 |
| M2 | 建造、人员、发电和手工到电动木工 | 主角独自起步，建发电设施后招募；取得电机解锁但建设仍扣材料；无电停机、缺电降速 |
| M3 | 基础运输、内部容量与自动切割 | 堵塞停机，疏通恢复；自动切割无需工人但分拣仍需；吞吐能比较 |
| M4 | 按确认范围加入塑料和生活供应 | 三个塑料地点各司其职；清洗不消费保留水；无未确认中间品 |
| M5 | 返回目标、倾倒与三结局、存档与重开 | 零倾倒／少量倾倒／达到阈值分别验证；阈值后返回按确认规则处理；暂停加速与存档保留所有结局状态 |
| M6 | 试玩、提示、美术声音、最终平台构建 | 从新游戏到结局的完整流程，无开发者注入；新开局与旧存档不混淆 |

M1 是首个范围检查点。若基本加工和压力循环未跑通，应重新评估实际工作量，而不是继续恢复已延期系统。

## 后续测试建议

玩法开始实现后，优先覆盖容易造成丢物品、资源透支或科技错误解锁的规则：库存容量边界、失败消费不改变库存、清洗保留水而饮水可使用、批量消费原子性、科技首次取得且不消耗材料、电机不解锁全自动版本。

物流和存档实现后，再增加堵塞恢复与结局状态恢复测试。本次只准备 Test Framework 依赖，不编写测试代码。
