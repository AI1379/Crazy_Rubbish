### 1.1 世界观

故事发生在遥远的未来。社会阶级高度固化，上层、中层、下层在空间上受到阻隔，各层普通人互不相知，洞作为层与层之间的连接。

上层资源过剩，将垃圾投入中层。玩家原本是上层垃圾处理场的工人，在倾倒垃圾时意外坠入中层，凭借垃圾处理知识取得当地人的认可，组织居民发展生产，希望返回上层。

中层人文明程度较低，能够接受工作安排并持续执行。主角在一般劳动能力上与居民没有区别；其特殊性是掌握上层知识，获得对应原料后能解锁相关科技。

玩家没有直接证据证明下层文明存在，也无法获得下层发展信息，但可以根据上层与中层的关系作出推测。

### 1.2 “涌现”的表达

垃圾持续出现，既提供文明发展的资源，也逐渐挤占生存与生产空间。

容易处理的垃圾充足时，玩家可能优先加工它们，忽略耗时、耗人工的垃圾。难处理垃圾逐渐堆积，影响附近人工效率；效率下降又使清理变慢，形成恶性循环。玩家由此产生改善产线或向洞中倾倒垃圾的选择。

### 1.3 核心成就感

- 通过分类、拆分和再利用，将垃圾变成有用途的原材料与产品。
- 将主角亲自劳动发展为居民协作，再发展到半自动化和持续自动生产。
- 通过布局、运输与岗位安排，提高单位时间内处理的垃圾量。

## 2. 第一区域地图、教学与扩区

### 一、本轮确认与设计边界

| 用户本轮确认 | 应用 |
|---|---|
| 约60—90分钟具备购买第二区域的条件 | 作为正常首次游玩节奏目标，不是强制等待 |
| 场地拥挤是扩地的主要推动力 | 生产、仓库、种植、住房、运输及堆积竞争土地 |
| 开局就能看到洞，不解释去向 | 洞从开局一直可用，不揭示下层文明或累计阈值 |
| 自行划地填埋，填满后永久失去该地 | 不额外赠送场外固定填埋区 |
| 分步骤教学，完成步骤后推进提示 | 教学进度不代替科技条件，也不锁住自由玩法 |
| 第一区域建立小型种植线 | 前期引导实际建设、种植并收获一批食物 |
| 地面全满仍持续来料 | 垃圾继续堆高，超量部分额外降低附近人工效率 |

本文件其余地图布局、教学任务、种植物品、地价、填埋容量与节奏为新增首版建议。已有配方、工资、居民财产、供电维护以相应专项文档为基础。第1、2区域允许现有玩法，地质勘探仅第3区域开放；扩区只用钱。返程载具类型、路线与配方继续待定。



### 二、玩家在这一区域经历什么

开局亲手从垃圾中取出工具和零件，用手工加工建成发电机。居民加入后，玩家第一次从“自己干活”变为“安排别人持续干活”，并开始负责工资和供应。电动木工与运输减少重复劳动，但机器、维护和员工住房占用更多土地。

随后太阳灯种植提供一部分稳定食物，难处理塑料越来越难忽视。玩家发现“多接收垃圾”并不等于“得到更多可立即用的资源”：仓库不能无限扩，填埋会吃掉自己的场地，放弃收益好的工序去处理低收益垃圾也有机会成本。洞则始终提供一种快速腾出空间的方法。

末段允许玩家用更合理的布局、轮换工序、局部自动化和有限填埋继续经营，也能攒钱购买第二区域。扩区后旧区保持来料及运行，不重置垃圾、工资、存款、填埋或倾倒记录。



### 三、地图与空间预算

根据用户“扩大基础空间”的要求，将初始可建设空地扩大为18×18格，共324格；18×18为本轮执行的首版建议。旧仓库、旧住房为既有设施，不扣这324格新建空地；初始垃圾山占48格，垃圾山、洞及连接道路位于外围可通行区域，不能当成免费的无限堆积场。

| 区块 | 首版位置关系 | 功能与限制 |
|---|---|---|
| 初始垃圾山 | 空地左侧，8×6格 | 固定来料点；只有48格来料格及已购买建设地可堆放 |
| 初始建设地 | 中央18×18格 | 可建设、存放、规划填埋，三者共享空间 |
| 旧仓库与旧住房 | 中央空地上侧 | 容量80／住房6；附近有通行空间 |
| 洞 | 左下侧，开局镜头可见或轻微平移可见 | 不可填平、建设或作为免费仓库；与垃圾山有可通行路径 |
| 第二区域边界 | 中央空地右侧 | 开局可查看购买价及范围，只需金钱即可购买 |
| 外围通道 | 连通上述区块 | 可走人，不可新增设备、堆物或划填埋，扩区后才按产权范围开放 |

垃圾山装不下的来料溢出到玩家建设地可用的最近空格，不消失、不停止上层产生垃圾。外围通道不是额外可用土地。用户确认垃圾山与全部可用地面均满时继续堆高，超量部分额外降低附近人工效率；垃圾不会覆盖设备使其停工，也不直接触发新的场地淹没失败。

普通地面存放仍按每格5容量单位规划；自然来料在无空格时允许在已有垃圾格继续堆高，这是超载状态，不是仓库容量扩大。每份垃圾保存实际数量，堆高有画面高度、超量及附近效率提示；没有隐藏队列。清走上层垃圾后同步减少超量和惩罚，不能只改显示而不改库存。

额外人工效率公式、清理恢复与自动化影响统一见第11章，地图配置采用同一规则。

### 建设示例

| 示例配置 | 新建占地 |
|---|---:|
| 手工木料、拆解、工作台、清洗 | 16格 |

| 电动木工 | 6格 |
| 一座新住房、一座新仓库 | 18格 |
| 小型种植地及太阳灯 | 10格，不含通行边 |
| 三地点塑料线 | 22格 |
| 合计设备占地 | 80格 |

这不是强制布局。扩大后，基础产线、种植与塑料线可以完成一轮布局试验；玩家不必刚接触半自动化就拆掉其他工作地点。再加入金属两地点18格、额外仓库9格、住房9格和填埋4格后，仍剩180格，尚未扣新增连接。

后期更完整的占地示例：上述80格基础设备＋金属18＋额外住房9＋两座额外仓库18＋自动木工9＋第三台发电机4＋两套额外种植与灯20＋两块填埋8＝166格；另留50格给运输、接口与通行，剩108格用于地面缓冲或继续扩产。扩产逐渐吃掉缓冲区，垃圾积压再造成压力，取代此前144格场地过早出现的拥挤。

324格比旧版144格增加180格，面积为原来的2.25倍。144格方案只保留于更新前备份。60—90分钟具备购买新区资金的目标仍用于校准；扩大后是否在这个时间段形成足够空间压力需要重新试玩核验，不把空间预算当作已经验证的经营模拟。

新建筑放置前显示是否堵住已有岗位或仓库的人员通路。无法到达的岗位不会靠瞬移工作；暂停时允许规划，恢复后按已有瞬间建设规则完成，无需另加施工计时。设备移除与库存旧址溢出继续沿用现有规则。



### 四、分步骤教学与首轮60—90分钟

时间是预期体验区间，完成条件以实际行为判断，不因到达某分钟自动解锁。玩家提前完成的内容记录在存档中，后续对应教学直接通过；提示通常只显示一个主步骤及其必要子项。

| 预期阶段 | 主提示与完成条件 | 玩家学到的内容 |
|---|---|---|
| 0—5分钟 | 拾取手锯、可用零件；搭手工木料地点，加工一批木板；主角完成简陋发电机并补燃料 | 工具→原料→建设→供电；获得居民认可 |
| 5—12分钟 | 招募至少1人；把人安排到木料地点；至少一次材料搬运并收到成品 | 持续岗位、人力运输、产线缓冲 |
| 12—20分钟 | 出售一次成品；查看工资账单；实际支付首张到期工资，或补齐已欠首张账单 | 工资进入居民钱包，生活购买与玩家现金分开 |
| 20—30分钟 | 接通旧住房电力，设置饮水保护量；清洗并修复一件衣物 | 供给、清洗用水和幸福度；有货与买得起是两种条件 |
| 25—40分钟 | 取得电机及对应机器锯片，建设并运行一批电动木工；查看维护岗位 | 机器提高速度，但还需操作、维护和电力 |
| 30—50分钟 | 完成太阳灯与种植地，播种并收获首批，再清洗成可用食物 | 空间、电、水和分阶段人力换取可控补给 |
| 40—60分钟 | 分选一批塑料，完成一次预处理与再加工；比较产时及仓储变化 | 难处理垃圾耗时长，不能仅靠库存数字判断价值 |
| 50—75分钟 | 从两个端口铺一条传送带；实际输送并输出一批产物；按需要取得送料组件改建自动木工 | 布局、接口、堵塞、局部自动化与维护 |
| 60—90分钟 | 查看空间分布、现金及第二区域范围，积攒购买资金 | 在继续整理和扩地之间选择；购买第二区域只看钱 |

教学明确指出填埋功能与永久占地代价，但不要求实际填埋；洞可以选择但从不作为必须完成的教学步骤。倒垃圾会影响结局，教学不能诱导玩家为完成步骤被迫损失好结局。

金属产线在材料满足时即可建立，作为可选分支；不把两座金属建筑设为上述教学的必须项。若先购买第二区域，未完成教学可以继续在那里完成，不要求回第一区域补全部步骤。首次教学期间也可以暂停、倍速、出售、分配岗位；不为教学另开隐藏的无工资时间。

教学步骤不奖励额外现金或刷新开局物资，防止地价实际依赖任务送钱。招募提示推荐先2—3人，玩家仍可立即招满5人。



### 五、资源发现与两条发展路线

首次拾取电机、加热元件、送料组件、种植灯组件、金属炉体与夹具都按已知知识自动解锁，不收费、不消耗该物品。不以时间、资产或教学完成替代这些条件。

| 路线 | 主要投入 | 初期优势 | 需要解决 |
|---|---|---|---|
| 木料与金属优先 | 电动木工、拆解，两地点金属及扩大发电 | 结构零件和工具补充，分散销售，建设材料来源较稳 | 塑料继续积压，熔炼残渣占地，电力负载高 |
| 塑料与生活供应优先 | 三地点塑料、清洗、种植与生活销售 | 回收难处理库存，得到高效率握柄，并减少部分外购 | 塑料多段占人，种植与清洗争夺水电，结构材料可能需买 |

两条路线都保留手工木料和拆解作为基础收入及部件来源，都能购买第二区域。不存在必须选一种“正确顺序”。首套部件来源保障只确保能建立路径，不把所有后续材料免费配齐。

回收送料组件首次取得自动解锁自动木工；钢铁零件首次取得解锁基础传送带与接口建设，仍需配方材料。原先未明确的两项解锁在本轮补齐，不将传送带硬锁到第二区域。



### 六、工资、招募与岗位前期落点

建议首次招募2—3人，玩家需要自己比较：人多加快整理，也会提前用完开局物资并增加首张工资。最多5名免招募费仍可立即加入。

第一张工资到期前60秒提示，界面不自动替玩家支付。欠薪不进入新手免责期；居民可以花存款继续消费，欠薪负面效果独立存在。教学说明“查看工资”和“真正发钱”是不同动作。

扩员优先建立住房，然后支付招募费。区内可用社区招募持续补充，不用累计在线时间刷名额；人口只受住房与玩家资金限制，不新增第一区域硬性人数上限。推荐正常末段5—8名员工；这不是购买新区条件。

连续岗位建议至少保留1名搬运，生产缺料时操作工释放去搬运，维护人员继续维护。工人不会为高优先新岗随意抛弃玩家手动指定的岗位；空闲人员自动补位。已有非手动指定人员可在完成当前批次后响应更高优先缺岗，剩余设备人工阶段等待；避免每秒来回切岗。

农业阶段性需求、清洗衣物和塑料多段适合轮换。最初不要求每处地点各一名永久专属操作工。真正需要同时运行更多设备时，再比较招募、买住房、增加仓库、自动运输或暂时停线。



### 七、扩地触发、地价与提示

第二区域首版地价建议200钱。开局可见可购买，玩家钱足时随时能买；没有通关第一区域、造齐设备、倒过垃圾、完成种植或达到指定科技的附加门槛。60—90分钟只是正常首次游玩的积攒目标。

为体现空间压力，按实际场地状态给提示：

| 场地信号 | 建议提示 | 可采取行动 |
|---|---|---|
| 可建设空地被设备／填埋／地面物品占用超过70% | “可用空间减少，注意保留运输与生活供应空间” | 清理、调整布局、暂停低效产线、准备扩地 |
| 仓库可用容量低于20%且持续60秒 | “仓库即将装满，先检查出口和销售计划” | 分散出售、增加仓储或送入回收 |
| 两处以上生产因满输出阻塞持续60秒 | “产出堵塞，增开机器可能无法提高处理量” | 检查运输、端口、配方和缓冲 |
| 可建设空地低于15%，且已能购买新区 | 展示边界与购买入口 | 玩家自行决定扩地，不强制跳转 |

这些提示不预告垃圾来料增长时间。打开购买界面显示地价、购买后余额及下一张预计工资；余额不足以发薪时提醒，但不增加强制留存工资条件。

200钱尚未通过完整60—90分钟模拟验证。首轮若熟练首次玩家普遍40分钟即可购买，应增加经营投入或校准地价；若正常经营90分钟仍缺钱，应先检查来料可出售价值、运输和工资，而不是强制拖延来料或阻止扩区。买地后至少有一段扩容收益，再逐渐面对新区域资源和旧区持续来料；第二区域具体面积与新资源另行设计。

### 建设、移动与岗位通则

建设需要配方材料及规定数量的空闲人员，主角可计入；建设正常时瞬间完成，暂停蓝图恢复运行后完成。建筑可旋转。机器建设人员默认转维护，可重新分配；每名维护工只维护一台设备。手工地点没有专职机器维护。

移动或拆除时内部物品先入仓库，超容量留旧址，阻止该位置建设并计压力；后续通过人员或传送带运走。拆除返还建造材料；种植进行中批次另按农业章处理，不能靠拆除返种子。

玩家设置需求与优先级，可指定个人到岗位。空闲人员自动寻找生产、建设、维护空缺。手动指定岗位不被自动抢占；其他工人可完成当前批次后响应更高优先空缺。停产释放操作工，维护人员继续。人工阶段缺对应工人即等待，不瞬移。

设备一次一配方，内部输入／输出各容当前配方两批。输出满停机，清出后恢复；恢复仍要满足人工、工具、电与维护条件。切换配方先转出旧物品，不删除材料，不突破缓冲容量。

## 8. 两地点金属加工与工具部件

### 一、完整流程与材质约束

取得垃圾 → 拆解并保留可用部件 → 按材质收集废料 → 金属原料处理地点 → 对应金属坯料 → 金属零件制造地点 → 零件或工具工作部件 → 建造设备或在手工台装配工具。

能够直接使用的回收部件优先保留，不要求为了取得坯料而把完整零件全部熔掉。直接回收省工省电；制造提供较稳定的补充来源，但需要人员、供电与场地。

| 材质分支 | 原料 | 中间产物 | 首批产物与用途 |
|---|---|---|---|
| 钢铁：结构用途 | 钢铁材料 | 钢铁坯料 | 钢铁零件，表示支架、连接件、紧固件等，支撑设备建设 |
| 钢铁：工具用途 | 工具钢废料 | 工具钢坯料 | 锤头、手锯锯片、螺丝刀金属杆 |
| 铜 | 铜材料 | 铜坯料 | 铜零件，表示导电连接片、接线端子等，支撑用电设备 |
| 铝 | 铝材料 | 铝坯料 | 铝零件，表示轻型壳体、罩板和支撑件 |

工具钢是钢铁类的用途分支，不新增第四大金属类别。不允许把普通钢板、铝料或铜料直接替代工具钢制造首批工具工作部件。不同工具实际适用的钢种不同，游戏把符合相应用途的钢料归入“工具钢”分支，成分识别和选择包含在加工流程里；这是库存简化，不代表所有工具钢可以不加区分地互换。

现实废钢分选需要考虑材质与钢种，碳含量会影响最终性能，因此不能把任意废钢都作为同一种优质工具原料。[世界钢铁协会：废钢回收流程](https://worldsteel.org/media/blog/2024/blog-scrap-and-the-steel-industry/)

以下物品可以在第一区域的垃圾输入中出现，不以购买第二区域为前提。具体投放量与增长曲线仍需结合完整游戏节奏配置。

| 垃圾物品 | 取得资源或部件 | 产线中的作用 |
|---|---|---|
| 废钢制支架、钢板外壳 | 钢铁材料；可用紧固件归入钢铁零件 | 最常见的结构材料来源 |
| 废铜线、铜管 | 铜材料；仍完整适用的导线可直接回收 | 供铜坯料及铜零件生产 |

| 废旧金属工作台 | 可用夹具、金属零件及对应材料 | 提供零件制造地点的工装 |

废铜线的绝缘层与金属分离后进入塑料分类；按实际塑料类别选择处理方式，不统一混入已有塑料熔融配方。原料处理以拆除附着物、分选和干式清理为主，初版不额外消耗肥皂或饮用水。

现实铝回收需要分选和去除混入物，再熔融形成锭或坯料；钢铁和铜的处理工艺并不因此相同。[铝业协会：再生铝生产](https://www.aluminum.org/secondary-production-101)

### 六、解锁、维护与自动化

首次取得钢铁、铜、铝材料分别自动解锁对应材料、坯料与零件配方；首次取得工具钢废料自动解锁工具钢坯料和三种工具部件配方。取得高温电炉组件解锁原料处理地点，取得回收夹具解锁零件制造地点。解锁不消耗物品、不占用研究时间，建设仍需完整配方。

即使配方先解锁，缺地点、工具或供电仍不能开工；这条产线可以在第一区域建立，不以地质勘探为前提。

原料处理需人工分选、装料和操作，熔炼使用电力；零件制造以人工加工为主。两处地点先允许传送带运料，再通过后续新设备替代机械加工和装卸劳动。自动化版本的具体解锁物品、建造配方与速度留到自动化产线设计时补齐，保留旧设备可继续工作的规则。

| 维护参数 | 首版建议值 |
|---|---|
| 最大耐久 | 100 |
| 运行损耗 | 每游戏秒0.2 |
| 正常维护恢复 | 每工人每游戏秒0.4，受人工效率影响 |
| 归零后 | 停机；维护继续，恢复至20后自动启动 |

两处地点均包含需维护的垃圾加工设备，生产与维护岗位分开；生产停工释放生产人员，维护人员继续工作。主动停用不损耗耐久。欠薪或暴动引发人工停工时，这两处有人工参与的地点停止生产，维护也停止；真正全自动、无需当时人力参与的设备按既有规则继续工作。

科技与维护数值由本轮补充设计确定，仍需测试供电不足、满缓冲、缺工具、欠薪、暂停／存档和耐久归零后的恢复情况。



### 七、玩家面对的取舍

1. 直接拆解取得可用零件，还是花人力和电力把零散废料重新加工。
2. 将工具钢优先用于工具补充，还是先把更多劳动力放在结构零件生产上。
3. 一处原料处理地点轮换多种材质，还是建设多处，分别处理不同材质，提高稳定供给。
4. 把资金用于工资和居民物资，还是购买炉体与工装、扩充金属产能。
5. 用自动化减少加工劳动，还是先增加回收与运输能力；自动化仍需维护，不等于没有人员成本。



### 八、现实参考与简化边界

本方案参考钢铁、铝、铜回收及工具制造的基本方向，将细分合金、炉内处理与成形工序合并到两个地点中。铜电气用途对纯度有要求，所以初版铜零件以导电用途相符的分选铜料为输入，杂质分选和工艺控制在内部体现，不将任意铜合金都归为合格电气用铜。[铜发展协会：铜的回收与纯度](https://archive.copper.org/environment/lifecycle/ukrecyc.php)

这些现实约束用于解释材料与设备为什么有区别。产率、加工时间、供电负载、损坏工具回收量及建设成本是原创游戏数值，不能当作现实生产参数。

勘探、持续开采和垃圾加工机器采用耐久与维护；传送带、手工地点、种植地不设专职机器耐久。简陋发电机按用户已确认“只需补燃料”运行，不额外加持续操作／维护人员。太阳灯负载0.8；其正常照明不额外向居民收费。高级火电多设施组合、详细供电优先级及高级机器配方继续待定。

### 来料首版

来料规律玩家不预知；后台首版：前10分钟期望8容量单位／分钟，10—30分钟12；此后每30分钟乘1.25，不设上限、不随科技变化。起步批次间隔随机40—80秒（后续频率增长参数待校准），批量围绕对应时间段期望加入±25%变化。生成器按实际间隔确定批量，避免频率随机使平均输入翻倍。初始垃圾山与新区域资源等级独立于这条时间增长。

一般来料的容量权重建议：木料35%、金属及旧设备25%、塑料20%、纺织品15%、未开封生活物资5%。先抽类别，再按容量预算抽物品，大件余量留给下一批，不把这些比例误用成人数或件数比例。不同区域可用不同等级池，但原区域不断料。





### 堆高规则

垃圾山装不下的来料溢出到玩家建设地可用的最近空格，不消失、不停止上层产生垃圾。外围通道不是额外可用土地。用户确认垃圾山与全部可用地面均满时继续堆高，超量部分额外降低附近人工效率；垃圾不会覆盖设备使其停工，也不直接触发新的场地淹没失败。

普通地面存放仍按每格5容量单位规划；自然来料在无空格时允许在已有垃圾格继续堆高，这是超载状态，不是仓库容量扩大。每份垃圾保存实际数量，堆高有画面高度、超量及附近效率提示；没有隐藏队列。清走上层垃圾后同步减少超量和惩罚，不能只改显示而不改库存。

首版额外效率倍率建议：在岗位原有4格压力范围内，计算超量Q=各暴露垃圾格max(0,该格容量－5)之和，正常参考容量C=范围内暴露垃圾格数×5；C为0时不加罚，否则倍率=max(0.4,1／(1＋Q／C))。这项乘原有面积压力倍率，整体人工效率仍遵守首版0.25下限，仓库与设备内部物品均不参与。Q/C为1时额外倍率0.5，Q/C为2时达到下限0.4。数值为本轮建议，需测试是否惩罚过重。

人工搬运、维护、填埋及种植操作同样按岗位或工人当前所在地受影响，全自动机器阶段与植物受光生长不直接因堆高变慢；运输上游和维护受人力影响仍可能拖慢整体产线。保护主角手工取物和垃圾取用操作可执行，避免满地后没有任何整理入口。

## 12. 填埋、洞与结局

| 选择 | 立刻收益 | 持续代价 | 后续状态 |
|---|---|---|---|
| 仓储与露天存放 | 保留未来可用资源 | 仓库、场地与搬运占用，露天可降低效率 | 可再投入产线 |
| 回收／发电 | 资源、收入、动力 | 人工、设备、电力与工具投入 | 副产物仍要处置 |
| 自行划地填埋 | 已填埋垃圾不再造成附近效率压力 | 永久占地，不能拿回内容物 | 填满地块失去建设用途 |
| 向洞中倾倒 | 快速释放垃圾占地，不需额外加工 | 运输机会成本；隐藏累计记录改变结局 | 玩家无下层信息，不能追回垃圾 |

### 填埋首版参数

- 最小规划2×2格，可组合。每4格用木板2、钢铁零件1标记建设，1名空闲工人瞬间完成；这是游戏建设预算，不复现现实填埋工程。
- 每格容纳20容量单位，2×2总容量80。只接受玩家选定的垃圾和加工残余，默认不填埋可穿衣服、可用工具等成品。
- 1名人员每批处理最多5容量单位，用10秒；先运到入口缓冲，再埋入。入口可接传送带，但不会自动完成掩埋，需要人员。
- 已掩埋内容不计垃圾压力；入口尚未掩埋的垃圾仍按暴露占格计入。发电灰渣照旧豁免压力，但占用填埋容量。
- 规划地从建设起就占用空间，不能同时放机器。填满格永久不能建设或恢复资源；首版建议已投入垃圾的格也不可撤销，以免把填埋当可反复掏出的仓库。该提前不可撤销规则是本轮建议，区别于已确认的“填满后永久失地”。
- 完全未使用的填埋规划可以撤销并返还建设材料；有内容的规划保留标记，不能靠拆围栏返地。首版不提供开挖或迁移填埋内容物。
- 无耐久或持续维护人员；掩埋作业受人工效率影响，暴动停工。填埋不是既有普通材料生产线的额外工序。

### 洞的早期表现

画面只提供洞口和“可投入物品，去向不明”的交互提示。不得出现下层名称、文明发展条、倾倒累计量或“再丢多少就失败”的提示。主角与工人不会因为路过自动坠落；只有明确倾倒命令丢物品。

手动倾倒首版每批最多8容量单位，交互2秒，运输仍按实际距离。工人倾倒需玩家指派类别；传送带接入洞需玩家明确设定过滤，默认未启用，不替玩家自动作出结局选择。可以随时停止，以洞的实际接收事件登记累计，不能在指令发出但运输未到时先计入。

入侵总量、延迟和临界返程判定仍留在全局结局设计待定。本轮不为60—90分钟前期节奏擅自设定整局隐藏阈值，也不强制第一次失败。

### 全局结局

#### 12.1 向下一层倾倒

通向下一层的洞一直可用。主角、工人和传送带均可运送垃圾，玩家可以选择倾倒种类并随时停止。

玩家看不到累计倾倒量，也不能观察下层发展。

累计倾倒量达到阈值后，经过一段游戏时间触发下层入侵剧情。下层利用垃圾实现技术爆炸，来到中层抢夺资源，中层被消灭。下层不制作实际可玩场景或战斗系统。

具体累计单位、不同垃圾的计入方式、阈值和延迟时间待定。

#### 12.2 三个主线结局

| 结局 | 已确认条件 | 表现与状态 |
|---|---|---|
| 好结局 | 从未向下一层倾倒垃圾，并成功返回上层 | 成功通关；具体画面、文字待定 |
| 普通结局 | 倾倒过少量垃圾、未达到入侵阈值，随后完成返回目标 | 普通结局；具体画面、文字待定 |
| 中层覆灭坏结局 | 倾倒达到阈值，延迟后发生下层入侵 | 中层被消灭，游戏失败 |

比赛版先采用静态画面和文字呈现结局，完整CG延期。恢复暴动系统后，比赛版还包含已确认的暴动失败：倒计时内未平息或未兑现承诺，主角被丢下去死亡，游戏结束，不进入下层继续游玩。

返回上层采用主角能够搭乘的载具，制造时必须同时使用垃圾回收材料与第三区域开采原料。具体材料名称、部件、数量、制造地点、科技条件和通关操作待定。载具类型与返回路线按用户要求暂不设计，保留待定；不自行决定载具动力或是否通过原洞返回。

“倾倒已达到阈值，但延迟剧情尚未发生时完成返回目标”的判定仍待定，不自行补出新结局。

### 1. 工资如何进入生活循环

玩家出售产物取得经营现金→手动发薪→员工个人钱包增加→员工自动购买饮水、食物、衣物与清洁用品，并支付住房和公共服务费用→物品实际消耗、现金转给相应收款方。

居民现金与玩家经营现金分开。居民买玩家库存，现金回到玩家；买外部商户的用品，现金离开玩家管理的经济；支付社区房租与公共服务费，现金进入社区账户。居民保留未花完的储蓄，不能为了让存款归零强制添加无限消费。

原有仓库直接出售保留：这是销售给中层其他买家，仍可不限量出售，并承受销售降价。自己雇用的居民具有有限钱包，不冒充无限购买力。两类出售共享商品库存，不能对同件物品重复结算。

| 现金 | 每居民单独钱包，内部用整数分记账 | 不能，只有实际交易或收费才转移 |
| 当前衣服 | 1件，记录剩余耐久 | 不能自动拿去出售 |
| 个人生活物品 | 仅必要的少量用品，或按次领取直接消耗 | 不能与玩家库存重复记账 |
| 玩家借用工具 | 属于玩家的生产资产 | 不算居民财产，领取不扣工资 |
| 欠薪应收款 | 与现金分别记录 | 未支付的工资不能拿去购物 |

首批居民各自携带5钱与既定初始衣物，作为一次性开局保障。后续招募者也携带5钱，来源记为迁入前存款，不从玩家现金扣；招募费30钱仍支付给社区组织。主角使用玩家现金支付自己的需求，不给主角另发工资或另造钱包。

工资、补薪和奖金都真实进入对应员工钱包。补薪按原账单的居民名单与份额偿付，不能把离职、死亡者旧工资改分给新招募者。新账单仍由当期员工平分。死亡者应收款的补付和遗产转交社区，不送给玩家；原欠薪记录仍按既定金额减少。首版无需可操作继承人。

首版不提供居民借贷、借钱给玩家、股票或复杂投资；现有3区域无需另做居民职业分层。



### 3. 居民消费表与首版预算

每个工资周期600秒，标准工资10钱。饮食每300秒消耗，租金和服务费每600秒结算，衣物按实际损坏才购买，不能每周期收一次整件衣服的钱。

| 支出 | 实际规则 | 正常周期平均支出 | 收款方 |
|---|---|---:|---|
| 饮水 | 每300秒1升，参考零售价0.5／升 | 1.00 | 库存所有者或外部商户 |
| 食物 | 每300秒1份，参考零售价1.5／份 | 3.00 | 库存所有者或外部商户 |
| 住房 | 有实际床位时，每周期收1钱 | 1.00 | 社区旧住房归社区；玩家新住房归玩家 |
| 肥皂 | 每600秒1清洁单位，满件参考价4／100单位 | 0.04 | 库存所有者或外部商户 |
| 衣服 | 当前衣物损坏时买1件，参考零售价10；寿命4800秒 | 1.25 | 库存所有者或外部商户 |
| 公共服务 | 社区照明／管理0.4，公共清洁0.1，实际提供才收 | 0.50 | 社区账户 |
| 自愿休闲 | 可选社区休闲服务，每周期最多1次、1钱 | 0—1.00 | 社区账户 |

上述表以参考最高价格计算；玩家商品受销售降价时，实际支出可能更低。住房、服务和休闲是现金费用，不凭空生产食物、抹布或电力。公共清洁只有既定扫帚、干净抹布等条件满足才收费；清洁用具仍由玩家供应及维护，服务费不替玩家采购这些生产／公共资产。

同住者房租按每人结算，不按整栋重复收费。住房电力负载仍按栋0.2；社区服务0.4不另代替电力消耗，不保证停电时仍有照明。社区照明／管理首版合并为一个服务状态，无服务则免该项。

首批旧住房提供免费入住到第一次发薪，到期后执行1钱社区房租。开局到第一次计划发薪前，食物、水和肥皂从玩家开局库存免费领取；这只是首轮引导政策，不是每次招募再提供一个免费周期。原开局库存不变，领取仍扣实物。



### 4. 居民怎样自动购买

继续使用“仓库自动领取”，不要求居民排队走到商店，不新增商店操作员或运输到住房的产线。给仓库增加“居民供应”页：指定可供商品、收费／免费、零售价和保留数量即可。

每次需求发生时依次判断：

1. 先使用居民已有可用物品；例如衣服未坏就不买新的。
2. 对标记免费供应的玩家库存直接领取消耗，不转移现金。
3. 对收费库存，检查个人可支配金额和库存，扣个人钱、加玩家钱、减库存；结算与领取一次完成。
4. 玩家库存缺货或没有可买配置时，可用个人现金向外部商户购买直接消耗，默认开启；不先入玩家仓库，也不扣玩家钱。
5. 缺钱或两处都无有效供给时，检查救助政策；仍未取得物品才进入原有缺供计时。

外部商户使用初期数值文档的购买价：食物1.5、水0.5、衣服10、肥皂4／件。外购按实际个人需求发生，没有自主囤积和转售；不改变玩家可购买生产材料的渠道。它是地图外中层交易的抽象，首版不模拟商户工人和仓储。

若玩家有货但定价更高，居民在相同满足需求效果下选择价格更低的一方；同价优先玩家库存。外部补给关闭后不会绕过设置，改为显示缺供原因。该开关默认开，避免把一次仓库堵塞误当成居民不需要生活用品。

饮水保护量约束工业清洗和向外出售，不阻止居民喝水。玩家批量出售之前先扣除居民已预留的生活用库存；仓库容量不因预留增加。生产领料和居民领取必须使用同一库存台账。

#### 零售与原市场价格的衔接

玩家对居民的零售参考价允许在0到表中价格之间调整，0代表免费；食物水禁止超出外购价。租金可在0—2之间设置，建议默认1。衣服和肥皂也不允许超过参考价，首版不引入任意高价消费剥削。

同种商品继续共享销售压力S。对居民出售的成交价=max(已有市场最低价，玩家设置的参考零售价×exp(－S/100))，再与玩家设置的价格上限取较小者；免费供应单独处理，不按最低价收钱。每次实际售出增加对应S，免费赠送不增加。卖出相关技术后，该商品零售价格也被永久最低价封顶，不能通过改用居民渠道绕过技术售卖损失；设置更低价或免费仍允许。

肥皂为居民共享供应实例，每领取1清洁单位按当前满件成交价的1/100结算，并按0.01件增加对应销售压力；剩余量保存。未消耗的肥皂仍占仓库一次容量。外购按清洁单位收费，用社区商户的共享皂库存抽象，不在居民钱包里另存一整件肥皂。

若市场更新需要重算最低价，全部商品使用同一份价格表；不在居民系统复制另一个最低价表。社区服务和房租没有商品销售压力，也不受出售技术影响。



### 5. 储蓄、优先级与大额消费

居民按“饮水→食物→必需衣物→个人清洁→住房收费→公共服务→休闲”的优先级支出。住房费用不会在扣掉最后一钱后再让居民因无法买水死亡。

每人的生活保护储蓄默认4钱，即下一工资周期2份食物加2升水的参考费用。饮水、食物和缺衣时的必需衣物可以动用保护储蓄；公共服务、租金和休闲只用保护储蓄以上的余额。免费物资或打折不降低该默认值，便于玩家理解；界面可展示“余额／建议保留4”。保护额会随基础需求或参考价正式改表而更新。

另设衣物储蓄目标10钱。居民只是在钱包中标记目标，不提前扣钱、也不每周期重复收服装费。非必需休闲需在消费后仍有“生活保护4＋衣物目标10”；达到目标后才有资格每周期消费一次。衣物更换时解除对应目标，再重新积累。不能把衣物目标从余额里减一次、实际购买再减一次。

在没有长期断薪时，正常消费能逐步积累换衣资金；个别周期购买衣物可能暂时付不了房租，此时显示房租未付，不因此驱逐或启动隐藏欠租死亡结局。超出周期现金的非必需费用不累积成贷款，未提供的可选服务也不收费。

有床位、无钱付租仍可居住，保护已有住房幸福度效果。本轮不新增房租债务与强制驱逐；失去床位按原有无住房规则处理。这样新增财产机制不会复制一套工资债务暴动。



### 6. 免费供给、补贴与紧急救助

玩家可对商品设置三种政策：

| 政策 | 居民支付 | 玩家付出 | 适用取舍 |
|---|---|---|---|
| 收费供应 | 自动付实际价 | 提供实物，取得零售收入 | 工资部分回流，居民仍需储蓄 |
| 免费供应 | 0 | 提供实物，无额外虚拟扣钱 | 集中保障生活，玩家承担物资来源成本 |
| 补贴供应 | 只付补贴后价格 | 少收钱；若代外购则付实际差额 | 针对衣物等大额消费或欠薪期 |

默认策略：首期引导免费，第一次计划发薪后收费；自动外购开启；紧急免费饮水开启，免费食物与代外购补贴默认关闭。

紧急饮水仅在居民付不起钱时从现有玩家水库存每周期最多提供2升／人，优先于工业用水，不凭空造水，不自动花玩家现金采购。免费配额每600秒刷新，不保存滚存；取得水按既定缺供恢复规则处理。玩家可开启免费食物及清洁，或用明确的玩家预算代购物资。

代外购预算默认0，玩家主动开启后可填每周期上限，例如10钱；按饮水优先顺序公平分配，不允许玩家现金为负。仓库免费实物不再额外扣一次现金；代外购实物直接交居民消费，不再同时扣库存。

免费物资、免租、消费补贴都不能抵工资欠款，不能清除欠薪次数或冒充奖金。员工用存款继续吃饭也不消除欠薪的效率负面影响。发奖金需无欠薪，奖金现金进入钱包；消费不会提前结束其人工加速效果，仍到下一次规定发薪时间停止。



### 7. 幸福度与暴动衔接

没有钱本身不直接扣幸福度；因为缺钱而实际缺水、缺衣等，才按已有需求效果降低效率或幸福度。缺水、缺食、缺货和买不起分别提示，便于玩家处理正确原因。

居民有储蓄但工资拖欠，仍保留欠薪判定；居民按时领薪但生活物资缺乏，仍可独立低幸福度暴动。租金未付而仍有住房不会重复施加无住房惩罚。

可选休闲服务实际支付并提供后增加5幸福度，作为临时加成600秒，不叠加，同一周期最多一次；不额外提高人工速度上限。它不能清除欠薪、不能替代暴动要求恢复的住房供电或基本供给。暴动发生后停止购买休闲，不用临时休闲掩盖原因；恢复判定仍检查实际原因及组织者恢复值。

暴动期间居民生活消耗继续，人工生产和维护停止。消费供应、外购及手动支付界面仍可用。欠薪暴动需支付发生时欠款的1/3，保存本次要求金额及进度；居民后来把这笔钱花掉也不撤销已完成的补发。新增欠薪独立入账，避免倒计时期间目标不断因其他消费变化。

承诺通过固定选项选择，取得的修复人手就是组织暴动的居民。承诺必须让暴动实际原因消失，例如修复住房供电并等待组织者幸福度恢复；沿用本次原倒计时，不因承诺重新计时。未兑现或超时未平息，主角被丢下去死亡，不进入下层继续游玩。

原有承诺只调用暴动参与者修复对应原因，不额外收承诺押金。本轮不增加第三种居民失败结局。



### 8. 对玩家经济的影响与示例

#### A. 同样10钱工资，居民的实际生活

长期最高参考价格下，每10分钟必需支出均摊6.79，最多再花1钱休闲，保留2.21—3.21。衣物不是平滑扣款，需观察实际存款。前几个工资周期因衣服未损坏且休闲储蓄门槛尚未达到，实际支出通常低于均摊值。

#### B. 钱都花到外部

5名员工工资50已由玩家支付。若他们向外部买食物、水、肥皂和衣服，付社区房租服务，工资从玩家经济流入外部；玩家不能因此再支付员工同一份食物成本。主角自己的生活需求仍由玩家负担，初期最高食物水成本每周期4。

#### C. 玩家有稳定的回收食品及饮水

每周期5名员工购买10份食物、10升水，按参考上限共付20钱回玩家。工资毛支出仍为50，扣这部分零售收入后暂为30；玩家另负担取得食品水的资源或采购成本。若全部外购后转售，同价成交成本20、收入最多20，没有额外利润；价格下跌还可能亏损。只有回收得到可用实物或后来建立自给生产，才实际降低净经营成本。

这20钱回流取决于居民有现金、玩家有货且供应政策收费，并非发薪自动返还；不会作为首期发薪前可用现金。

#### D. 玩家免费供给

工资50仍转入员工钱包，居民不再付对应商品费用。若玩家外购供应5名员工两餐两次水，另付20钱；合计70，尚未算主角4和其他费用。若供应来自垃圾回收，只有实物机会成本，不能虚构额外20现金支出。免费供给使员工更能积蓄，减少断供风险。

#### E. 不发工资

现有存款能够暂时买到食物，却会逐渐减少；欠薪计数持续增长。饮水救助能避免部分早期死亡，但不补发工资、不平息欠薪暴动。玩家须真的向居民转账，才恢复工资记录。这形成产率、产品收入、居民生活和欠薪之间的联系。



### 9. 账务与更新顺序

首版账户：玩家经营现金、每名居民钱包、外部商户收款累计、社区收款累计。外部销售收入另记外部资金流入。社区余额只用于记录和显示，不在本轮模拟社区财政自动扩建。

每次交易必须同时完成现金双方变化及物品变化；现金转移不生成金币，物品消费不退款。使用整数分处理钱，肥皂分次费用使用余数累计，整件总额不能因反复取整消失。

工资到期的处理顺序：标记应发账单、清除奖金、处理玩家已下达的手动支付，再执行同一时间点居民需求与非必需费用。到期不自动发薪；若尚未下达支付，显示账单并用居民已有钱结算，不偷偷等待玩家发薪。首期免费政策在第一次计划发薪时间终止，和是否真正付款无关。

每个居民各自保存需求时钟，出生／加入不重置全体需求时钟；开局首批居民可按固定错开相位消耗，减少瞬间争抢。相同优先级轮换居民顺序；一人处理本轮最高优先需求后再处理下一人，不能让第一人买完所有东西后其他人无水可喝。

存档需记录：个人钱包、当前物品、工资账单及领取份额、保护目标、商品供应政策、销售压力、费用时钟、救助配额、未收费用提示、暴动固定补薪要求、所有库存占用及货币余数。读档不重发迁入资金、不刷新免费引导、不重置救助配额。

死亡时释放岗位与床位，个人遗产现金归社区，借用工具退回玩家库存；私人衣物可作为遗留物留在现场，按耐久回收，不自动变新。额外招募费高于迁入存款，且玩家不能取遗产，不提供反复招募杀死来刷钱的收益。



### 10. 界面与制作范围

居民列表新增“现金、预计基本支出、缺钱／缺货原因”三列；详情显示财产、支出流水、工资应收款。玩家顶部仍只显示经营现金，避免误把全体居民现金当成可支付工资的资金。

仓库供应页显示食品水及衣物的库存、生活保留量、参考／当前零售价、免费或补贴政策；每周期财务页区分工资毛支出、居民零售收入、外销收入、玩家代购和净现金变化。公共服务与社区费用不用新增一套建筑产线。

制作优先顺序：个人钱包及工资转账→食物水自动付费与实物消费→免费救助与缺供提示→衣物和肥皂→房租与服务→可选休闲。以上属于当前完整机制；若调整比赛版范围，需明确删减，不能把未实现部分宣称已完成。

首轮需要游戏内验证：5／10／20人口，收费／免费两种政策，连续拖欠与补发，衣物集中损坏，仓库断货且个人有钱，个人没钱但仓库有货，暴动期间消费、死亡遗产与存档读档。本文仅做账务与预算纸面核验，尚未在Unity中验证。

## 15. 操作、界面与存档

- 玩家直接控制主角移动和拾取；管理操作覆盖整个已解锁地图。
- 建筑与基础传送带采用网格摆放，建筑可旋转。

- 暂停时可以规划、放置建筑、移动设备、分配人员、出售物品；暂停放置的建筑在恢复运行后完成。

- 正常游戏可以保存、退出后继续。
- 各种结局后返回首页；新开一局从最初开始。失败后读取旧存档的规则见待定清单。

界面需让玩家理解垃圾堆积、人员不足、缺原料、缺工具、输出堵塞、缺电等生产状态；当前提示见本章，最终视觉布局仍待制作。

### 第一区域状态提示

地点状态必须区分：缺原料、缺对应工具、缺操作工、缺维护工、耐久不足、缺电、输出满、缺生产用水、路径不通。点击原因跳转到有关库存、岗位或电网，不只显示“效率低”。

居民状态区分：欠薪、个人现金不足、仓库缺货、外购关闭、无床位、断电和具体生活需求缺供。资金栏分玩家经营现金与居民钱包，不把居民有存款误解释为玩家可以发工资。

场地视图提供三种开关：设备与线路、地面垃圾和填埋占用、附近人工压力。显示实际已发生的压力，不能展示未来垃圾或下层发展。图例明确仓库里的垃圾不计局部压力，地面加工品同样占地方。

拆机器时预览返还材料及内部物品、仓库剩余容量和预计旧址溢出。填埋提交第一批前明确说明该格不可恢复，不用频繁弹窗；洞不添加剧透警告或教学指定倾倒。



核心存档项目：区域产权、库存与物品状态、岗位及手动指定、配方缓冲、工具耐久、设备耐久、燃料与灰渣计数、电网、来料时钟与批次成分、堆高数量、填埋内容、种植阶段、居民钱包与工资账单、消费政策与配额、价格压力、教学进度、洞实际接收记录、暴动原因与倒计时。

## 16. 纸面检查、制作与试玩验收

### 开局材料路径

从固定拾取物出发，两个人工地点消耗废木料8、紧固件4。手工加工两批消耗废木料8，产木板6和碎屑2。工作台用木板4、钢铁零件2；发电机用钢铁零件6及指定组件、电线2。此时至少剩废木料64、钢铁零件22、木板2、电线6，无须先制造金属、塑料或电机，主角可独立完成。

### 首次发薪桥接

五名员工首期工资50。专职木工10批耗400秒；预留20%搬运及等待损失需500秒，产30份木板。按逐件销售且暂不计算价格恢复，收入约78.14，付薪后约28.14。初始食品和水覆盖首个工资周期；燃料可先用余下废木料。这个检查假定材料送达、工具可用、玩家实际销售并发薪，不表示游戏自动发钱。

此方案仅验证起步不被硬性成本锁死。在玩家免费供应全部食物水且完全外购的情况下，五名员工工资5钱／分钟，6人购买食物水约2.4钱／分钟，合计7.4。新增个人消费机制后，员工自己支付的外购食物水不能再次计为玩家支出；玩家只支付自身需求及主动补贴，居民零售收入另记。前10分钟常规木料来料扣发电燃料后不足以单靠木板长期覆盖全部成本，必须利用初始库存过渡并逐渐拆解、修复衣物及分散销售产品。永久技术降价仍构成有意保留的经营代价。

### 建议优先落地

1. 先实现手工木料、拆解、工作台和单体发电机，完成主角认可与首次发薪闭环。
2. 接上有限仓库、基础需求、人工搬运和可读的堵塞原因提示。
3. 实现三地点塑料线和电动木工，验证轮换、维护、少水停工。
4. 接上传送带、自动木工与两地点金属线，测试供电不足和缓冲溢出。
5. 用游戏内模拟验证20分钟、40分钟和完整3—4小时经济；本文件未完成后两区域节奏与最终通关时间校准。

首轮关注：首次工资前是否能赚50；饮水是否被清洗挤占；5人轮换是否可理解；塑料是否慢但值得利用；溢出是否仍有补救空间。先调时间、来料和价格，不同时叠加事故等额外变量。

### 第一区域验收

| 场景 | 前期必须能成立的结果 |
|---|---|
| 初始0钱，只用固定可拾取物 | 主角独自完成发电机，不循环依赖其他产线 |
| 仅招2人／立即招5人 | 两者都可起步，成本与处理速度有差异 |

| 断电、照料无人、缺水 | 种植暂停对应阶段，不凭空消耗下一阶段材料 |
| 用完小型填埋 | 80单位实际减少，占4格，不赠送第二块土地 |
| 仓库满后移动或拆设备 | 原料正确溢出旧址，可通过现有运输恢复 |
| 暴动期间 | 人工与农业操作停，已供电生长与全自动机器可继续，维护停 |

| 存档读档 | 工资、钱包、种植阶段、填埋内容、洞记录和教学步骤保持 |

本轮仅核验设备占地、种植输入输出、基础预算与文档规则衔接。尚未在Unity运行；实际垃圾堆高与额外压力、无倾倒可行性、两路线收入、200地价与60—90分钟目标必须试玩验证。初始空间已扩大为324格，需要重新核验60—90分钟内的积压和扩产节奏。整局3—4小时仍需第2、3区域及返回流程共同校准，不能凭第一区域目标推断已经完成。



### 完整游戏要求

3个区域需有实际可玩内容，买地、跨区物流、勘探开采和最终返回流程可运行；不能用第一区域可玩代替完整作品。六组恢复系统必须纳入相应验收。正常存档可继续，新开局从最初开始。结局后回首页；是否保留失败前旧存档的具体比赛规则仍需统一，当前旧案有“可读旧存档”与早期失败后重开两种表述，不由本次合并擅自改定。

最新剩余制作时间、人员分工与实现进度未知，本次只合并策划；不宣称已经实现或验证完整3—4小时流程。
