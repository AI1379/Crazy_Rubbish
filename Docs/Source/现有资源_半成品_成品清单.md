# “涌现”现有资源、半成品与成品清单

整理日期：2026年10月6日。

依据目前已经确认的策划内容整理，仅汇总现有名称、来源与用途，不新增物品或配方。第一表为已细化的资源与物品；设施和后续扩展中的类别另列。分类按主要用途整理，同一物品可以兼作居民用品、生产消耗品或建设材料。

表中的功能名称不等于已经确定最终显示名称或库存形式。尚未确定的物品细分、数量、耗时、价格和回收比例均保持待定。
